## I. 模式切换 (The Foundation)

| 命令                        | 切换到模式        | 描述                           |
| :------------------------ | :----------- | :--------------------------- |
| **`i`**                   | Insert       | 在**光标当前位置**进入插入模式。           |
| **`a`**                   | Insert       | 在**光标后一个位置**进入插入模式 (Append)。 |
| **`o`**                   | Insert       | 在**当前行下方**插入新行。              |
| **`O`**                   | Insert       | 在**当前行上方**插入新行。              |
| **`v`**                   | Visual       | 进入**字符**可视化模式 (选中字符)。        |
| **`V`**                   | Visual       | 进入**行**可视化模式 (选中整行)。         |
| **`<C-v>`**               | Visual Block | 进入**块**可视化模式 (选中矩形块)。        |
| **`<Esc>`** 或 **`<C-[>`** | Normal       | 退出所有模式，返回 Normal 模式。         |

## II. 移动与跳转 (Navigation)

### 1. 行内移动 (Intra-line)

| 命令            | 范围  | 描述                         |
| :------------ | :-- | :------------------------- |
| **`w`**       | 单词  | 向前跳转到下一个单词开头。              |
| **`b`**       | 单词  | 向后跳转到上一个单词开头。              |
| **`e`**       | 单词  | 向前跳转到当前单词末尾。               |
| **`f{char}`** | 字符  | 向右查找 `{char}` 字符，并跳转到该字符上。 |
| **`F{char}`** | 字符  | 向左查找 `{char}` 字符，并跳转到该字符上。 |
| **`;` / `,`** | 字符  | 重复/反向重复上一个 `f/F/t/T` 查找。   |
| **`0`**       | 行   | 移动到行首（第一个字符）。              |
| **`^`**       | 行   | 移动到第一个非空白字符。               |
| **`$`**       | 行   | 移动到行尾。                     |

### 2. 跨行与文件跳转 (Inter-line & File)

| 命令                    | 范围   | 描述                                                     |
| :-------------------- | :--- | :----------------------------------------------------- |
| **`gg`**              | 文件   | 移动到文件第一行。                                              |
| **`G`**               | 文件   | 移动到文件最后一行。                                             |
| **`{数字}G`**           | 文件   | 移动到文件的指定行号。                                            |
| **`%`**               | 括号   | 在匹配的括号 **`(), [], {}`** 之间跳转。                          |
| **`{` / `}`**         | 段落   | 向上/向下跳到下一个空行或段落开头。                                     |
| **`H` / `M` / `L`**   | 屏幕   | 移动到屏幕的 **High (顶行)** / **Middle (中行)** / **Low (底行)**。 |
| **`<C-f>` / `<C-b>`** | 屏幕   | 向前/向后滚动一整屏。                                            |
| **`<C-o>` / `<C-i>`** | 跳转列表 | 跳到上一个/下一个光标跳转位置。                                       |

## III. 操作符与文本对象 (The Core)

Vim 的操作遵循 **[操作符] + [动作/文本对象]** 的模式。

### 1. 核心操作符 (Operators)

| 操作符           | 描述           | 常用示例                         |
| :------------ | :----------- | :--------------------------- |
| **`d`**       | Delete (删除)  | `dw` (删除单词) / `dd` (删除行)     |
| **`c`**       | Change (改变)  | `ciw` (改变内部单词) / `cc` (改变一行) |
| **`y`**       | Yank (复制)    | `yy` (复制一行) / `y$` (复制到行尾)   |
| **`p`**       | Paste (粘贴)   | 在光标**后**粘贴。                  |
| **`P`**       | Paste (粘贴)   | 在光标**前**粘贴。                  |
| **`>` / `<`** | Shift (缩进)   | `>i{` (增加内部花括号内容的缩进)         |
| **`=`**       | Format (格式化) | `=a{` (自动格式化整个花括号块)          |

### 2. 文本对象 (Text Objects)

| 文本对象    | 边界        | **`ci` (Change Inner)** | **`ca` (Change A round)** | 描述                                |
| :------ | :-------- | :---------------------- | :------------------------ | :-------------------------------- |
| **单词**  | `w`       | `ciw`                   | `caw`                     | **`i`** 不含空格，**`a`** 包含单词后的一个空格。  |
| **花括号** | `{` 或 `B` | `ci{` / `ciB`           | `ca{` / `caB`             | **`i`** 仅操作内容，**`a`** 包含 `{}` 符号。 |
| **圆括号** | `(` 或 `)` | `ci(` / `ci)`           | `ca(` / `ca)`             | **`i`** 仅操作内容，**`a`** 包含 `()` 符号。 |
| **引号**  | `"` 或 `'` | `ci"` / `ci'`           | `ca"` / `ca'`             | **`i`** 仅操作引号内的内容，**`a`** 包含引号本身。 |
| **标签**  | `t`       | `cit`                   | `cat`                     | 用于 HTML/XML 标签。`cat` 替换整个标签块。     |
| **段落**  | `p`       | `cip`                   | `cap`                     | **`i`** 不含周围空行，**`a`** 包含周围空行。    |

## IV. 实用编辑与撤销 (Essential Edits)

| 命令             | 模式     | 描述                      |
| :------------- | :----- | :---------------------- |
| **`u`**        | Normal | 撤销上一个操作 (Undo)。         |
| **`<C-r>`**    | Normal | 重做上一个撤销 (Redo)。         |
| **`r`**        | Normal | 替换光标下的**单个字符**，不进入插入模式。 |
| **`~`**        | Normal | 反转光标下字符的大小写。            |
| **`J`**        | Normal | 将当前行与下一行合并 (Join)。      |
| **`ctrl + a`** | Normal | 增加光标下数字的值。              |
| **`ctrl + x`** | Normal | 减小光标下数字的值。              |
| **`.`**        | Normal | **重复上一个**编辑命令（强大的宏级重复）。 |

## V. 搜索与文件操作

| 命令                | 模式     | 描述                       |
| :---------------- | :----- | :----------------------- |
| **`/pattern`**    | Normal | 向下搜索 `pattern`。          |
| **`?pattern`**    | Normal | 向上搜索 `pattern`。          |
| **`n` / `N`**     | Normal | 跳转到下一个/上一个匹配项。           |
| **`*` / `#`**     | Normal | 搜索光标下的单词（向下/向上）。         |
| **`:w`**          | 命令     | 保存文件。                    |
| **`:q`**          | 命令     | 退出窗口。                    |
| **`:wq` 或 `:x`**  | 命令     | 保存并退出。                   |
| **`:e filename`** | 命令     | 编辑/打开新文件。                |
| **`:bd`**         | 命令     | 删除当前缓冲区 (Buffer Delete)。 |
