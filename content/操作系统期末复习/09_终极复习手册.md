# 操作系统 · 终极复习手册

> 在开始前，先记住这门课的骨架：
>
> **操作系统 = 资源管理者**。它管理四种资源：CPU（进程）、内存（存储）、外设（设备）、磁盘（文件）。
> 五种管理衍生出五章内容，但它们共享一套设计哲学：**抽象 + 调度 + 保护**。

---

## 一、必背概念清单（填空题 & 选择题出处）

### 1.1 操作系统的四大特征

| 特征 | 含义 | 一句话 |
|------|------|--------|
| **并发** | 宏观同时，微观交替 | 单核跑多任务 |
| **共享** | 资源被多进程共用 | 互斥共享（打印机）/ 同时共享（磁盘） |
| **虚拟** | 一个物理实体变多个逻辑对应物 | 虚拟内存、虚拟CPU |
| **异步** | 执行过程走走停停 | 完成时间不确定 |

> **并发是最基本的特征**，其余三个都以并发为前提。

---

### 1.2 四大管理功能

| 功能 | 核心任务 | 核心数据结构 |
|------|----------|-------------|
| 处理机管理 | 进程控制、同步、通信、调度 | PCB |
| 存储器管理 | 分配、保护、映射、扩充 | 页表 / 段表 |
| 设备管理 | 缓冲、分配、驱动 | DCT / COCT |
| 文件管理 | 存储空间、目录、读写保护 | FCB / i-node |

---

### 1.3 操作系统的四种体系结构

| 结构 | 核心思想 | 优点 | 缺点 |
|------|----------|------|------|
| 无结构 | 一堆过程互相调用 | 开发快 | 难维护 |
| 模块化 | 按功能分模块，接口交互 | 正确性高 | 接口难定义 |
| 分层式 | 单向依赖，每层隐藏下层 | 易验证 | 效率低 |
| 微内核 | 内核最小化，服务在用户态 | 可靠、可移植、可扩展 | 消息传递慢 |

---

### 1.4 并发 vs 并行（送分也送命）

| | 并发 | 并行 |
|--|------|------|
| 时间 | 同一时间**间隔** | 同一**时刻** |
| 硬件 | 单处理器即可 | 必须多处理器 |
| 进程 | 只有动态进程可并发 | 多CPU时进程可并行 |
| 程序 | ❌ 静态程序不能并发 | — |

---

### 1.5 进程 vs 线程（高频辨析）

| | 进程 | 线程 |
|--|------|------|
| 资源 | 拥有资源的**基本单位** | 只拥有少量私有资源 |
| 调度 | 传统OS的调度单位 | 现代OS的调度单位 |
| 地址空间 | 独立 | 同一进程内共享 |
| 通信 | IPC（管道/消息/共享内存） | 直接读写共享变量 |
| 创建开销 | 大（建页表、地址空间） | 小（建栈和TCB） |
| 切换开销 | 大（切地址空间、刷TLB） | 小（同一进程内不切地址空间） |

---

### 1.6 线程三类型

| 类型 | 管理方 | 阻塞影响 | 多CPU |
|------|--------|----------|-------|
| 用户级(ULT) | 线程库 | 一个阻塞→全进程阻塞 | 不能用 |
| 内核级(KLT) | OS内核 | 一个阻塞不影响其他 | 能用 |
| 混合 | 两者结合 | 较好 | 能用 |

---

### 1.7 阻塞 vs 挂起（必混淆）

| | 阻塞 | 挂起 |
|--|------|------|
| **在哪里** | 在内存中 | 在外存中 |
| **等什么** | 等事件（I/O、信号） | 等被激活调入内存 |
| **谁操作** | 进程自己block | OS/父进程suspend |
| **组合** | 阻塞且挂起 = 外存+等事件 | — |

---

### 1.8 PCB的三大类信息

```
PCB
├─ 进程标识符（ID、父ID、用户ID）
├─ 处理机状态（通用寄存器、PC、PSW、栈指针）
└─ 进程控制信息（状态、优先级、事件、链接指针、页表、资源清单）
```

> PCB 是**进程存在的唯一标志**，常驻内存。

---

### 1.9 死锁

**四个必要条件**（缺一不死锁）：互斥、请求并保持、不可剥夺、环路等待

**四类处理方法**：
| 方法 | 思路 | 典型技术 |
|------|------|----------|
| 预防 | 破坏必要条件 | 一次申请所有/有序分配/SPOOLing |
| **避免** | 分配前检查安全 | **银行家算法** |
| 检测 | 资源分配图简化 | 找不可简化子图 |
| 解除 | 撤进程/夺资源 | 选代价最小的 |

---

### 1.10 存储器关键概念

| 概念 | 一句话 |
|------|--------|
| 逻辑地址 → 物理地址 | 靠 MMU（页表 / 段表 / 重定位寄存器） |
| 内部碎片 | 分配给进程的区域内没用的空间（固定分区、分页） |
| 外部碎片 | 分区之间零散的空闲区（动态分区、分段） |
| 紧凑 | 把所有进程移到一端，合并碎片 → 需要动态重定位 |
| 覆盖 | 同进程内模块复用内存（程序员设计） |
| 交换 | 不同进程换入换出内存（OS自动） |

---

### 1.11 分页 vs 分段（必考辨析）

| | 分页 | 分段 |
|--|------|------|
| 划分依据 | 系统固定大小 | 用户逻辑结构 |
| 大小 | 固定（4KB） | 可变 |
| 地址维度 | 一维 | 二维（段号+偏移） |
| 碎片 | 内部碎片 | 外部碎片 |
| 共享 | 难（跨页） | 易（段级） |
| 动态链接 | 难 | 易 |
| 段页式 | — | —（先分段后分页，取两者优点） |

---

### 1.12 虚拟存储器

| 特征 | 含义 |
|------|------|
| 离散性 | 进程不必连续存放 |
| 多次性 | 不必一次全部装入 |
| 对换性 | 运行中可换入换出 |
| 虚拟性 | 逻辑上扩充容量 |

**理论依据**：局部性原理（时间局部性 + 空间局部性）

**抖动**：页框数 < 工作集 → 频繁缺页 → 系统吞吐量骤降

---

### 1.13 文件系统

| 概念 | 含义 |
|------|------|
| 逻辑结构 | 用户视角（顺序/索引/散列） |
| 物理结构 | 磁盘视角（连续/链接/索引） |
| FCB | 文件控制块（存文件元信息） |
| i-node | 索引结点（UNIX：将文件名和描述信息分离） |
| FAT | 文件分配表（显式链接的集中指针表） |
| 按名存取 | 文件系统最基本的功能 |

---

### 1.14 I/O 控制四代

| 方式 | 传输单位 | CPU参与 | 并行 |
|------|----------|---------|------|
| 程序查询 | 字节 | 全程 | 无 |
| 中断驱动 | 字节 | 每字节中断 | 有 |
| DMA | 块 | 开始+结束 | 有 |
| 通道 | 多块 | 一条命令 | 三者并行 |

---

### 1.15 缓冲

| 类型 | 处理一块时间 |
|------|-------------|
| 单缓冲 | Max(C,T) + M |
| 双缓冲 | Max(C,T)（M忽略） |
| 循环缓冲 | 多缓冲+N指针 |
| 缓冲池 | 系统公用 |

引入目的：**缓解CPU和I/O速度不匹配的矛盾**

## 二、计算题公式速查

### 2.1 调度算法核心公式

```
周转时间 = 完成时间 - 到达时间
带权周转时间 = 周转时间 / 服务时间
响应比 R = (等待时间 + 服务时间) / 服务时间 = 1 + 等待时间/服务时间
```

**六种算法一句话**：
| 算法 | 核心规则 | 抢占 |
|------|----------|------|
| FCFS | 先到先得 | 否 |
| RR(q) | 每人q时间，用完排队尾 | 是 |
| SPN | 谁服务时间最短谁先 | 否 |
| SRT | 谁**剩余**时间最短谁上 | 是 |
| HRRN | 谁响应比最高谁先 | 否 |
| FB | 多队列降级 | 是 |

**FB 时间片规律**：第 i 队列时间片 = 2^(i-1)（或固定 q），用完降级到下一队列。

---

### 2.2 死锁最少资源数公式

n 个进程，各需 k 个同类资源，不出现死锁的最少资源数：

$$m \geq n \times (k-1) + 1$$

> 最坏情况：每个进程拿了 k-1 个，都在等最后一个。此时再加 1 个，至少有一个能完成。

---

### 2.3 信号量值含义

| S.value | 含义 |
|---------|------|
| > 0 | 有 S.value 个可用资源 |
| = 0 | 资源刚好分完，无等待 |
| < 0 | \|S.value\| 个进程在排队等待 |

P 操作：先减 1，若 < 0 则阻塞（让权等待）  
V 操作：先加 1，若 ≤ 0 则唤醒一个等待者

---

### 2.4 分页地址转换

```
页号 P = 逻辑地址A ÷ 页面大小L（整除）
页内偏移 d = A mod L
物理地址 = 页框号F × L + d
```

**位运算**（页面大小 = 2^n）：
- 高 m-n 位 = 页号
- 低 n 位 = 页内偏移

---

### 2.5 有效访问时间（EAT）

```
EAT = (TLB命中率) × (TLB时间 + 内存时间)
    + (TLB未命中率) × (1-缺页率) × (TLB时间 + 2×内存时间)
    + (TLB未命中率) × 缺页率 × (TLB时间 + 内存时间 + 缺页处理 + TLB时间 + 内存时间)
```

**简化版**（TLB时间忽略，不考虑TLB）：
```
EAT = (1-p) × t_mem + p × t_fault
```
其中 p = 缺页率

---

### 2.6 磁盘访问时间

```
总访问时间 = 寻道时间 + 旋转延迟 + 传输时间

旋转延迟(平均) = 1/(2×转速) = 半圈时间
转速单位转换：rpm / 60 = 转/秒；每转时间 = 1/转每秒

传输时间 = 传输扇区数 / 每转扇区数 × 每转时间
```

---

### 2.7 多级页表

```
每页能放的页表项数 = 页面大小 / 页表项大小

设每级索引 b 位（每页放 2^b 项），页面 2^n 字节
级数 k 满足：b × (k-1) + n ≥ 虚地址位数
```

---

### 2.8 文件最大容量（混合索引）

```
直接块容量 = N_direct × 块大小
一级间接 = (块大小/盘块号大小) × 块大小
二级间接 = (块大小/盘块号大小)² × 块大小
```

## 三、经典问题解题模板

### 3.1 PV 操作解题三步法

**Step 1**：找出所有同步和互斥关系
- 互斥 → 多个进程不能同时做的事
- 同步 → 谁必须等谁做完

**Step 2**：为每个关系定义一个信号量
- 互斥 → mutex = 1
- 同步 → 信号量初值 = 资源数量（0 表示"还没准备好"）

**Step 3**：在正确位置放 P 和 V
- P(mutex) 和 V(mutex) 在**同一进程**中包围临界区
- V(S) 在"产生信号"的进程中，P(S) 在"等待信号"的进程中
- ⚠️ **多个 P 时，先 P 资源信号量，后 P 互斥信号量！**

---

### 3.2 银行家算法标准步骤

```
1. 计算 Need = Max - Allocation
2. 计算 Available = 总量 - ΣAllocation
3. 请求检查：
   a) Request ≤ Need？
   b) Request ≤ Available？
4. 试探分配：Available减、Allocation加、Need减
5. 安全性算法：
   Work = Available, Finish全false
   循环：找 Need≤Work 且 Finish=false 的进程
        → Work += 该进程的Allocation, Finish=true
   全部Finish=true → 安全；否则不安全
```

---

### 3.3 页面置换算法做题步骤

```
1. 画表格：帧1到帧n
2. 逐时刻：访问新页面
   - 在帧中 → 命中，更新访问信息（LRU则更新序，CLOCK则置R=1）
   - 不在帧中 → 缺页！
     - 有空帧 → 直接装入
     - 无空帧 → 按算法选一个淘汰
3. 统计缺页次数和缺页率
```

**CLOCK 特别注意**：
- 命中时：R 位置 1，指针**不动**
- 缺页淘汰时：扫描找 R=0，沿途把 R 都清 0，指针移到淘汰位置后一格

---

### 3.4 调度算法甘特图

```
1. 画时间轴从 0 开始
2. 在到达时刻标记新进程
3. 在每个决策点（进程完成/时间片到/新进程到达）判断就绪队列和下一执行者
4. 写出每个进程的完成时间
5. 算周转时间 = 完成 - 到达
```

---

### 3.5 磁盘调度做题步骤

```
1. 列出所有请求和当前磁头位置
2. 按算法规则逐个选：
   - FCFS：按请求顺序
   - SSTF：每次选距磁头最近的
   - SCAN：向一个方向扫到端，反向
   - C-SCAN：单方向扫到端，跳回起点
3. 累加移动距离
```

## 四、跨章节串联理解

### 4.1 贯穿全课的"虚拟化"思想

| 被虚拟的实体 | 虚拟技术 | 上层看到什么 |
|-------------|----------|------------|
| CPU | 进程调度（时分复用） | 每个进程以为自己独占CPU |
| 内存 | 虚拟内存（请求分页） | 程序以为有远大于物理内存的空间 |
| 打印机 | SPOOLing | 每个用户以为自己独占打印机 |
| 磁盘 | 文件系统 | 一堆块变成了"文件和目录" |

> **任何计算机科学问题都可以通过加一层抽象来解决。**

---

### 4.2 并发引发的连锁问题

```
并发执行
  ├→ 需要协调访问共享资源 → 互斥（临界区+信号量）
  ├→ 需要保证执行顺序 → 同步（PV操作的V/P配对）
  ├→ 可能互相等待 → 死锁（四大条件+银行家算法）
  └→ 程序结果不确定 → 进程封闭性被破坏
```

---

### 4.3 碎片问题的统一视角

| 分配方式 | 是否有内部碎片 | 是否有外部碎片 |
|----------|:------------:|:------------:|
| 固定分区 | ✅ | ❌ |
| 动态分区 | ❌ | ✅ |
| 分页 | ✅（最后一页） | ❌ |
| 分段 | ❌ | ✅ |
| 段页式 | ✅（页内碎片） | ❌ |

> 解决方案：离散分配消除外部碎片（分页）；紧凑技术消除外部碎片（需动态重定位）。

---

### 4.4 空间换时间 / 时间换空间

| 策略 | 例子 | 本质 |
|------|------|------|
| 空间换时间 | 快表(TLB)、Cache、缓冲 | 用硬件成本买速度 |
| 时间换空间 | 虚拟内存、覆盖、交换 | 用磁盘时间买内存空间 |
| 空间换空间 | 多级页表 | 用更小的表代替大表 |

## 五、高频易错点

| 易错点 | 正确理解 |
|--------|----------|
| ❌ 并发=并行 | ✅ 并发是宏观同时；并行是微观同时 |
| ❌ 程序可以并发 | ✅ 只有进程可以并发，程序是静态的 |
| ❌ 就绪→阻塞可以发生 | ✅ 必须经过执行态 |
| ❌ 阻塞=挂起 | ✅ 阻塞是等事件（在内存），挂起是被换出（在外存） |
| ❌ 模式切换一定伴随进程切换 | ✅ 不一定（I/O 中断处理完继续原进程） |
| ❌ TLB 未命中=缺页 | ✅ TLB 未命中可能页在内存（只更新TLB） |
| ❌ FIFO一定页面越多缺页越少 | ✅ FIFO有 Belady 异常（反而增加） |
| ❌ 所有算法都不饿 | ✅ SPN/SRT/SSTF 可能造成饥饿 |
| ❌ 信号量初值可以为负 | ✅ 记录型信号量初值≥0 |
| ❌ V操作可能阻塞自己 | ✅ V操作不会阻塞，P操作才会 |
| ❌ 磁盘访问时间=寻道时间 | ✅ = 寻道 + 旋转延迟 + 传输 |
| ❌ 页表在CPU里 | ✅ 在内存里（TLB 在 CPU 里） |
| ❌ 系统调用不需要模式切换 | ✅ 必须从用户态切换到内核态 |
