# 真题分析与命题规律

> 基于考研820真题、历年期末试卷、2025样题的综合分析

---

## 一、考试题型结构（推测）

基于课件+往年试卷：

| 题型 | 题量 | 分值 | 考什么 |
|------|------|------|--------|
| **填空题** | 15-20空 | ~20分 | 关键概念/数字/属性（死记硬背型） |
| **选择题** | 10题 | ~20分 | 概念辨析、算法属性判断 |
| **简答题** | 5-6题 | ~25-30分 | 概念解释、机制描述、对比分析 |
| **分析计算题** | 2-3题 | ~25-35分 | 调度算法、页面置换、银行家、地址转换 |
| **PV操作题** | 1题 | ~5-10分 | 写信号量、写PV代码 |

**核心分值分布**：计算题 + PV操作 ≈ 35-40分，是决定性的大题。

## 三、命题规律总结

### 规律1：概念题 → 面试式问答

820冲刺笔记中45道简答题是标准题库。考试中的简答题基本都是从这些题目中出或变形。**直接背答案不够**，需要理解背后的原理能用自己的话表述。

### 规律2：计算题 → 套路固定

五大计算题型有标准解题流程：
- 调度题：画甘特图 → 算完成时间 → 算周转/带权
- 置换题：画页面表格 → 逐帧记录 → 数缺页次数
- 银行家：列出矩阵 → 找安全序列 → 判断请求是否允许
- 地址转换：拆页号+偏移 → 查表 → 组物理地址
- PV操作：分析同步互斥关系 → 定义信号量 → 写代码

### 规律3：PV操作 → 三大模型变种

考试不会考"标准生产者消费者"，而是考它的变种。你练熟三大模型：
1. 生产者-消费者（含单缓冲/N缓冲/多个生产者消费者）
2. 读者-写者（含读者优先/写者优先/公平）
3. 哲学家（含死锁避免策略）

然后遇到新题 → 类比到最接近的模型 → 改造

### 规律4：填空题 → 精确记忆教材原话

820冲刺笔记中有近50道填空题。特点：需要**精确记忆**，差一个字可能就错。如："进程的基本状态有____、____、____"（就绪、执行、阻塞）

## 四、与课件作业的对应关系

课件作业其实就是考试题的来源：

| 课件章节 | 作业内容 | 对应考试题型 |
|----------|----------|-------------|
| 01 概述 | 总结OS基本功能 | 简答题 |
| 02_1 进程控制 | 五状态模型分析、PCB存储内容、进程vs线程 | 简答题+填空题 |
| 02_2 调度 | A/B/C/D/E 五种算法周转时间计算 | **计算大题** |
| 02_3 同步死锁 | 独木桥PV、阅览室PV、哲学家、银行家 | **PV大题+计算大题** |
| 03_1 基本内存 | 分区分配、伙伴系统 | 简答题+填空题 |
| 03_2 虚拟内存 | FIFO/LRU/CLOCK/OPT 缺页次数 | **计算大题** |
| 03_2 虚拟内存 | 有效访问时间、工作集、抖动 | 简答+小计算 |
| 04 设备管理 | 缓冲计算、磁盘调度 | 简答题 |
| 05 文件系统 | 位示图、文件组织对比 | 简答+小计算 |

**结论**：作业题 = 考试重点。课件作业中要求计算的，考试大概率出同类型计算题。
