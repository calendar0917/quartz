## 一、选择题（每小题2分，共30分）

1. 下列描述不属于操作系统功能的是（ ）
   A、CPU调度
   B、作业管理
   C、文件加密
   D、设备管理

2. 进程和程序的本质区别是（ ）
   A、动态性和静态性
   B、共享性和独立性
   C、顺序性和并发性
   D、单个进程和多个进程

3. 下列关于进程状态转换的描述中，错误的是（ ）
   A、就绪态→运行态：进程被调度
   B、运行态→就绪态：时间片用完
   C、阻塞态→就绪态：等待的事件发生
   D、运行态→阻塞态：进程主动放弃CPU

4. 在多进程系统中，以下哪种情况可能发生死锁?（ ）
   A、进程数小于资源数
   B、资源不可剥夺
   C、资源可共享使用
   D、进程按顺序申请资源

5. 某系统中有3类资源R1、R2和R3，可用资源数分别为9、3、6。在T0时刻系统状态如下表所示，此时系统处于安全状态。T0时刻的安全序列是（ ）

   | 进程 | 最大需求 | 已分配 |
   |------|----------|--------|
   |      | R1 R2 R3 | R1 R2 R3 |
   | P0   | 5  3  3  | 1  1  1  |
   | P1   | 4  1  3  | 2  1  0  |
   | P2   | 3  2  2  | 2  0  1  |

   A、<P0,P1,P2>
   B、<P1,P0,P2>
   C、<P2,P1,P0>
   D、<P2,P0,P1>

6. 在采用分页存储管理的系统中，页表的作用是（ ）
   A、实现虚拟地址到物理地址的映射
   B、实现内存的分配和回收
   C、实现虚拟内存的扩充
   D、实现内存的保护

7. 抖动（Thrashing）现象是指（ ）
   A、CPU利用率过高
   B、系统频繁进行页面置换
   C、内存分配不足
   D、进程频繁创建和销毁

8. 在段页式存储管理中，要访问一条指令或数据，至少需要访问内存（ ）次
   A、1
   B、2
   C、3
   D、4

9. 下列磁盘调度算法中，可能会出现饥饿现象的是（ ）
   A、FCFS
   B、SCAN
   C、SSTF
   D、C-SCAN

10. 缓冲技术的主要目的是（ ）
    A、提高CPU利用率
    B、提高内存利用率
    C、缓解速度差异

## 二、填空题（每小题2分，共10分）

1. 操作系统的主要特征包括并发性、共享性、\\和异步性。
2. 在生产者-消费者问题中，若信号量empty的初值为10，表示\\。
3. 在分页系统中，若逻辑地址空间大小为2^32，页面大小为4KB，则页内地址偏移量需要\\位。
4. 磁盘I/O控制方式主要有程序查询方式、中断方式、DMA方式和\\方式。
5. 操作系统内核通常提供\\、内存管理、I/O管理三种基本服务。

## 三、应用与计算题（共50分）

1. 以下程序最后打印*、$、#各多少个?（6分）

```c
void main() {
    printf("*\n");
    for (int i = 0; i < 2; i++) {
        fork();
        printf("$\n");
    }
    printf("#\n");
}
```

2.（10分）已知A、B、C、D和E进程的到达时刻分别为0、2、4、6和8，服务时间为3、6、4、3和2。采用反馈调度算法，进程首次到达时，首先进入优先级最高的就绪队列（即第1队列），然后依次降级进入第2、3等数据队列。在第i队列中执行的时间片长度为2^(i-1)。请计算上述进程的周转时间及带权周转时间（归一化周转时间）。

3. 一台计算机有一个cache，主存储器和用作虚拟存储器的磁盘，假设访问cache中的字需要20ns的定位时间。如果该字在主存储器中而不在cache中，则需要60ns的时间载入cache，然后再重新开始定位。如果该字不在主存储器中，则需要12ms的时间从磁盘中提取，然后需要60ns复制到cache中，然后再开始定位。cache的命中率是0.9，主存储器的命中率是0.6，在该系统中访问一个被定位的字所需要的平均时间为多少（单位：ns）?（10分）

4. 设某作业占有7个页面，如果在主存中只允许装入4个工作页面（即工作集为4），作业运行时，实际访问页面的顺序是1,2,3,6,4,7,3,2,1,4,7,5,6,5,2,1。试用FIFO与LRU页面调度算法，列出各自的页面淘汰顺序和缺页中断次数，以及最后留驻主存4页的顺序。（假设开始的4个页面已装入主存）（10分）

5. 设磁盘的I/O请求队列中的磁道号为：98,183,37,122,14,124,65,67，磁头初始位置为50，若采用FCFS（先来先服务）和SSTF（最短寻道时间优先）的磁盘调度算法。磁头分别移动多少磁道。（4分）

6. 某磁盘共有200个柱面，其编号为0-199，假定磁头刚完成91号柱面的访问，现有一个请求队列在等待访问柱面。该请求队列访问的柱面号分别为：190、97、90、54、180、30、166、108。试比较最短寻道时间有限算法和FIFO扫描算法的磁盘调度，请分别计算磁头移动的总磁道数。（10分）
