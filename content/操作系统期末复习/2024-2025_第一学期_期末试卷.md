A、动态性和静态性

**3.** 关于进程状态转换，**错误**的是（ ）

A、就绪态→运行态：进程被调度  
B、运行态→就绪态：时间片用完  
C、阻塞态→就绪态：等待的事件发生  
D、运行态→阻塞态：进程主动放弃 CPU  

<details>
<summary>答案与解析</summary>

**答案：D**

运行态→阻塞态：进程因等待某事件而**被动**进入阻塞（等 I/O 完成、等信号等），不是"主动放弃 CPU"这么简单。且运行→就绪才是主动放弃 CPU（时间片完、被抢占）。

严格来说，block() 确实是进程自己调用的（主动行为），但这个说法可能会让人误解为"进程想放弃就能放弃"。实际上 D 表述的是对的——block() 是进程主动调用的。

让我们重新审视：A✅ B✅ C✅。D 呢？课件原文："正在执行的进程，当发现上述某事件时，由于无法继续执行，于是进程便通过调用阻塞原语 block() 把自己阻塞"。所以 block() 确实是**进程主动调用的**。D 的表述"主动放弃 CPU"在字面上是正确的。

但从考试角度来说，这道题可能考的是另一个点——运行→阻塞的**根本原因**是"等待某事件"，而不是"主动放弃"这种表述。

重新分析：四个选项都是正确的转换关系描述。可能题目出得不够严谨，或者考的是"不正确的是哪个状态转换方向"。最常见的考法是"不可能发生的状态转换"，也就是说"哪些转换方向不存在"——如就绪→阻塞是不存在的。

如果一定要挑一个有问题的，可能是 D——运行→阻塞并不是"主动放弃 CPU"的意愿行为，而是"被迫暂停"（因为等 I/O），虽然 block() 是自己调用的，但出发点是"无法继续执行"。

**最佳答案：D**——block()虽是进程自己调用，但根本原因是"无法继续执行"而非"主动放弃"。

</details>

B、SCAN  
C、SSTF  
D、C-SCAN  

<details>
<summary>答案与解析</summary>

**答案：C**

- SCAN/C-SCAN：磁头来回扫描，不会遗漏，无饥饿

<details>

### 第 1 题（6 分）—— fork() 输出

```c
void main() {
    printf("*\n");
    for (int i = 0; i < 2; i++) {
        fork();
        printf("$\n");
    }
    printf("#\n");
}
```

打印 `*`、`$`、`#` 各多少个？

<details>
<summary>答案与解析</summary>

逐步骤推导：

**i=0 前**：1 个进程，打印 1 个 `*`

**i=0（第一次循环）**：
1. fork() → 进程数变成 2
2. 父子各执行 `printf("$")` → 打印 2 个 `$`

此时有 2 个进程，且都已经完成 i=0 的循环体。

**i=1（第二次循环）**：
1. 每个进程 fork() → 进程数变成 4
2. 4 个进程各执行 `printf("$")` → 打印 4 个 `$`

此时有 4 个进程，都已完成循环。

**循环结束后**：
4 个进程各执行 `printf("#")` → 打印 4 个 `#`

**统计**：
- `*`：1 个
- `$`：2 + 4 = **6 个**
- `#`：**4 个**

**关键**：第二次循环中的 `printf("$")` 是在 fork 之后由**所有进程**（包括新 fork 出的子进程）一起执行的。每次 fork 后进程数翻倍。

</details>

### 第 2 题（10 分）—— 反馈调度（FB）

A(0,3), B(2,6), C(4,4), D(6,3), E(8,2)。第 i 队列时间片 = 2^(i-1)，新进程进第 1 队列（时间片=1）。计算周转时间和带权周转时间。

<details>
<summary>答案与解析</summary>

时间片：Q1=1, Q2=2, Q3=4, Q4=8...

**逐时刻推导**（维护多个就绪队列）：

```
初始: Q1=[A(3)]
t=0: A在Q1执行q=1 → t=1时A时间片到(剩2), 降级到Q2
t=1: Q1空, Q2=[A(2)]。Q2时间片q=2 → 执行A
t=2: B到达, 进入Q1=[B(6)]。A在Q2运行中(剩1)。
t=3: Q2时间片到, A(剩1)降级到Q3。Q1=[B(6)] → 执行B(q=1)
t=4: B时间片到(剩5), 降级到Q2。C到达, Q1=[C(4)]。Q2=[B(5)], Q3=[A(1)]
     Q1优先→执行C(q=1)
t=5: C时间片到(剩3), 降级到Q2。Q1=[]。Q2=[B(5),C(3)]
     Q2执行q=2 → 执行B
t=6: D到达, 进入Q1=[D(3)]。B在Q2运行中(剩3)。
t=7: Q2时间片到, B(剩3)降级到Q3。Q3=[A(1),B(3)]
     Q1=[D(3)]→执行D(q=1)
t=8: D时间片到(剩2), 降级到Q2。E到达, Q1=[E(2)]。Q2=[C(3),D(2)]
     Q1优先→执行E(q=1)
t=9: E时间片到(剩1), 降级到Q2。Q1=[]。Q2=[C(3),D(2),E(1)]
     Q2执行q=2→执行C
t=11: Q2时间片到, C(剩1)降级到Q3。Q3=[A(1),B(3),C(1)]
      Q2=[D(2),E(1)]。执行Q2→执行D(q=2)
t=13: D完成, Q2时间片到。Q2=[E(1)]
      Q2执行q=2→执行E
t=14: E完成。Q2空。Q3=[A(1),B(3),C(1)]
      Q3执行q=4→执行A
t=15: A完成。Q3=[B(3),C(1)]→执行B
t=18: B完成。Q3=[C(1)]→执行C
t=19: C完成✓
```

| 进程 | 到达 | 服务 | 完成 | 周转 | 带权 |
|------|------|------|------|------|------|
| A | 0 | 3 | 15 | 15 | 5.00 |
| B | 2 | 6 | 18 | 16 | 2.67 |
| C | 4 | 4 | 19 | 15 | 3.75 |
| D | 6 | 3 | 13 | 7 | 2.33 |
| E | 8 | 2 | 14 | 6 | 3.00 |

平均周转 = (15+16+15+7+6)/5 = **11.8**
平均带权 = (5+2.67+3.75+2.33+3)/5 ≈ **3.35**

注意：FB 算法中 A 虽短(3)但被反复降级，反而最晚完成——这就是 FB 对短进程不友好的场景（因为刚降级就被新进程抢走 Q1）。

</details>

### 第 3 题（10 分）—— 有效访问时间

Cache 命中率 0.9，命中时 20ns。Cache 未命中但**内存命中率 0.6**（在未命中 Cache 的前提下），需 60ns 载入 Cache 后重新定位。未命中内存则需 12ms（磁盘） + 60ns 载入 Cache。

求**平均访问一个字的时间**（ns）。

<details>
<summary>答案与解析</summary>

**理解题意**：
- Cache 命中（概率 0.9）→ 20ns
- Cache 未命中（概率 0.1）：
  - 内存命中（在 Cache 未命中前提下概率 0.6）→ 60ns（载入 Cache）+ 20ns（重新定位）= 80ns
  - 内存也未命中（概率 0.4）→ 12ms（磁盘）+ 60ns（载入 Cache）+ 20ns = 12,000,080ns

**计算**：

EAT = 0.9 × 20ns  
    + 0.1 × [ 0.6 × (60 + 20)ns + 0.4 × (12×10^6 + 60 + 20)ns ]

  = 18ns + 0.1 × [ 0.6 × 80 + 0.4 × 12,000,080 ]
  = 18ns + 0.1 × [ 48 + 4,800,032 ]
  = 18ns + 0.1 × 4,800,080
  = 18ns + 480,008ns
  = **480,026ns ≈ 0.48ms**

**结论**：虽然 Cache 命中率高达 90%，但一旦缺页（需 12ms 磁盘访问），平均时间就被大幅拉高。**这就是缺页的代价**。

</details>

### 第 4 题（10 分）—— 页面置换（FIFO vs LRU）

7 个页面，工作集 = 4（已装入 1,2,3,6）。访问序列：1,2,3,6,4,7,3,2,1,4,7,5,6,5,2,1。

用 FIFO 和 LRU 分别求缺页次数和最后驻留的 4 个页面顺序。

<details>
<summary>答案与解析</summary>

初始装入：[1,2,3,6]，假设按 1→2→3→6 顺序进入（1 最早）。

#### FIFO

```
初始: [1,2,3,6]  队列顺序: 1-2-3-6(1最早)

访问序列（只列缺页时刻）：
4: 缺! 淘汰1 → [2,3,6,4]  队列: 2-3-6-4
7: 缺! 淘汰2 → [3,6,4,7]  队列: 3-6-4-7
3: 命中（3在帧中）
2: 缺! 淘汰3 → [6,4,7,2]  队列: 6-4-7-2
1: 缺! 淘汰6 → [4,7,2,1]  队列: 4-7-2-1
4: 命中
7: 命中
5: 缺! 淘汰4 → [7,2,1,5]  队列: 7-2-1-5
6: 缺! 淘汰7 → [2,1,5,6]  队列: 2-1-5-6
5: 命中
2: 命中
1: 命中
```

FIFO 缺页次数 = 初始 4 次 + **6 次** = 10 次？等，初始的 1,2,3,6 是"假设已装入"，如果题目说"开始 4 个页面已装入主存"意味着前 4 次访问不产生缺页。

实际缺页 = 序列中不在当前帧的访问次数。初始 4 个已在内存，前 4 次(1,2,3,6)命中。
从第 5 次访问(4)开始计算缺页：缺页 = 6 次（4,7,2,1,5,6 各缺一次）

**FIFO 缺页次数 = 6 次**

**最后驻留**：[2,1,5,6]

---

#### LRU

```
初始: [1,2,3,6]  LRU序: 1-2-3-6(1最久)

访问序列：
4: 缺! 淘汰LRU=1 → [2,3,6,4]  LRU: 2-3-6-4
7: 缺! 淘汰LRU=2 → [3,6,4,7]  LRU: 3-6-4-7
3: 命中。LRU序: 6-4-7-3
2: 缺! 淘汰LRU=6 → [4,7,3,2]  LRU: 4-7-3-2
1: 缺! 淘汰LRU=4 → [7,3,2,1]  LRU: 7-3-2-1
4: 缺! 淘汰LRU=7 → [3,2,1,4]  LRU: 3-2-1-4
7: 缺! 淘汰LRU=3 → [2,1,4,7]  LRU: 2-1-4-7
5: 缺! 淘汰LRU=2 → [1,4,7,5]  LRU: 1-4-7-5
6: 缺! 淘汰LRU=1 → [4,7,5,6]  LRU: 4-7-5-6
5: 命中。LRU序: 4-7-6-5
2: 缺! 淘汰LRU=4 → [7,6,5,2]  LRU: 7-6-5-2
1: 缺! 淘汰LRU=7 → [6,5,2,1]  LRU: 6-5-2-1
```

LRU 缺页 = 序列中缺页次数 = 11 次（几乎所有不在初始集中的都缺了，且频繁切换）

**LRU 缺页次数 = 10 次**（需要数一下：从 4 开始，4✓,7✓,3命中,2✓,1✓,4✓,7✓,5✓,6✓,5命中,2✓,1✓ → 10 次缺页）

最终驻留：[6,5,2,1]

</details>

### 第 5 题（4 分）—— 磁盘 FCFS vs SSTF

请求：98,183,37,122,14,124,65,67。磁头初始 50。分别用 FCFS 和 SSTF 计算磁头移动总磁道数。

<details>
<summary>答案与解析</summary>

#### FCFS

服务顺序 = 请求顺序：98,183,37,122,14,124,65,67

移动距离：
50→98(48) → 98→183(85) → 183→37(146) → 37→122(85) → 122→14(108) → 14→124(110) → 124→65(59) → 65→67(2)

总移动 = 48+85+146+85+108+110+59+2 = **643**

#### SSTF

从 50 开始，每次选最近的：
