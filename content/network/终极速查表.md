## 五层协议体系结构

| 层次 | 功能 | 传输单元 | 代表协议 |
|:--:|------|---------|---------|
| 应用层 | 应用进程通信 | 报文 | DNS, HTTP, SMTP, FTP, DHCP |

## 时延四分类

| 时延 | 定义 | 公式 | 产生位置 |
|------|------|------|---------|
| 发送 | 发送数据帧的时间 | 数据长度/发送速率 | 机器内部发送器 |
| 传播 | 信号在信道中传输 | 距离/传播速率 | 信道（机器外部）|
| 处理 | 分析首部、检错、查表 | — | 主机/路由器 |
| 排队 | 队列等待 | — | 路由器队列 |

$$总时延 = 发送 + 传播 + 处理 + 排队$$

## 奈氏准则 & 香农公式

$$奈氏：码元速率_{max} = 2W$$

$$香农：C = W \log_2(1 + S/N)$$

## CRC 计算口诀

```
1. 除数位数减一 = n → 原数据后面加 n 个 0
2. 模2除法（异或）→ 得余数 R（不足 n 位前面补 0）
3. 发送数据 = 原数据 + R
```

❌ 最容易犯的错：**忘记加 n 个 0**、余数不补前导 0

## CSMA/CD

- 争用期 = **51.2 μs**（10M以太网）
- 最短帧长 = **64 字节**
- 指数退避：k=min(重传次数,10)，r∈[0,2ᵏ-1]，等待 r×2τ
- 重传 **16 次**仍失败则丢弃

## IP 数据报分片

- 片偏移单位 = **8 字节**
- **DF**=1 不分片，**MF**=1 后面还有，MF=0 最后一片
- 每片**标识**相同

## ARP 工作流程

```
同一局域网：
  查缓存 → 有则用；无则广播 ARP 请求 → 目的主机单播响应

不同局域网：
  用 ARP 找路由器的 MAC → 发给路由器 → 路由器继续转发
```

## TCP 首部关键字段

| 字段 | 说明 |
|------|------|
| 序号 | 本报文段第一个数据字节的编号 |
| 确认号 | **期望收到下一个字节的序号**（确认号=N → N-1都已收）|
| SYN | 连接建立 |
| FIN | 连接释放 |
| ACK | 确认号有效 |
| 窗口 | 允许对方发送的字节数 |

## TCP 三握手 & 四挥手

```
握手：A→[SYN,seq=x]→B→[SYN+ACK,seq=y,ack=x+1]→A→[ACK,ack=y+1]→B
挥手：A→[FIN,seq=u]→B→[ACK,ack=u+1]→B→[FIN+ACK,seq=w,ack=u+1]→A→[ACK,ack=w+1]→B(等2MSL)
```

## TCP 拥塞控制四算法

| 算法 | 触发条件 | cwnd 变化 | ssthresh |
|------|---------|----------|--------|
| **慢开始** | 初始/超时后 | 每RTT翻倍（指数）| — |
| **拥塞避免** | cwnd ≥ ssthresh | 每RTT+1（线性）| — |
| **快重传** | 3个重复ACK | 立即重传 | — |
| **快恢复** | 3个重复ACK后 | cwnd=ssthresh | cwnd/2 |

**超时**：**ssthresh=cwnd/2, cwnd=1 → 慢开始**
**3个重复ACK**：ssthresh=cwnd/2, cwnd=ssthresh → 拥塞避免

发送窗口上限 = **min(rwnd, cwnd)**

## 常见易错点

| 易错 | 纠正 |
|------|------|
| "高速链路比特传得快点" | ❌ 传播速率不变，减少的是发送时延 |
| CRC 忘加 n 个 0 | 除数 n+1 位→加 n 个 0 |
| 可用主机不-2 | 全0=网络地址，全1=广播，都要减去 |
| IP 分片偏移忘除8 | 片偏移以**8字节**为单位 |
| 检验和忘取反 | 反码求和后再**取反码** |
| 确认号 = 已收字节数 | ❌ 确认号 = 期望收到的**下一个**字节序号 |
| TCP 半关闭 | A发FIN后A→B方向关闭，B→A方向还可发 |
