## 1. 物理层基本概念

物理层解决：如何在连接各种计算机的**传输媒体**上传输数据**比特流**。

- 尽可能屏蔽不同传输媒体和通信手段的差异
- 物理层协议常称为**物理层规程** (procedure)

### 四个特性

| 特性 | 内容 |
|------|------|
| **机械特性** | 接口接线器的形状、尺寸、引线数目和排列 |
| **电气特性** | 接口各条线上电压的范围 |
| **功能特性** | 某电平的电压的意义 |
| **过程特性** | 各种可能事件的出现顺序 |

> ⚠️ 传输媒体本身不在物理层协议内，在物理层协议之下。有人把物理媒体称为"第0层"。

## 2. 数据通信基础知识

### 2.1 通信系统模型

三大部分：**源系统（发送方）→ 传输系统（传输网络）→ 目的系统（接收方）**

### 2.2 常用术语

- **消息**：通信的载体（话音、文字、图像、视频等）
- **数据**：运送消息的实体，有意义的符号序列
- **信号**：数据的电气或电磁表现
  - **模拟信号**：连续取值
  - **数字信号**：离散取值
- **码元**：代表不同离散数值的基本波形。二进制编码有2种码元（0和1）

### 2.3 通信方式

| 方式 | 特点 |
|------|------|
| 单工通信 | 只有一个方向，无反向交互 |
| 半双工通信 | 双向但不能同时收发 |
| 全双工通信 | 双向同时收发 |

### 2.4 编码与调制

**基带信号**：来自信源的信号，含较多低频成分。

**调制**分为两类：

| 类型 | 说明 | 转换后的信号 |
|------|------|------------|
| **基带调制** | 波形变换，数字信号→另一种数字信号 | 编码(coding) |
| **带通调制** | 用载波调制，搬移到较高频段 | 模拟信号 |

#### 常用编码方式

| 编码 | 规则 | 自同步能力 |
|------|------|:--:|
| 不归零制 | 正电平=1，负电平=0 | ✗ |
| 归零制 | 正脉冲=1，负脉冲=0 | ✗ |
| **曼彻斯特** | 位中心向上跳变=0，向下跳变=1（或相反）| ✓ |
| **差分曼彻斯特** | 位中心始终跳变；边界有跳变=0，无跳变=1 | ✓ |

> 曼彻斯特编码缺点：所占频带宽度比原始基带信号增加一倍。以太网使用曼彻斯特编码。

#### 基本带通调制方法

| 方法 | 变化参数 |
|------|--------|
| 调幅(AM) | 载波振幅 |
| 调频(FM) | 载波频率 |
| 调相(PM) | 载波初始相位 |

**正交振幅调制 QAM**：振幅+相位混合调制，例如16种组合可表示4bit/码元，提高数据传输率4倍。

## 3. 信道的极限容量 ⭐

### 限制码元传输速率的两个因素：
1. **信道能通过的频率范围** → 奈氏准则
2. **信噪比** → 香农公式

### 3.1 奈氏准则（奈奎斯特定理）

无噪声、低通信道中：

$$码元传输最高速率 = 2W \ (码元/秒)$$

其中 W = 信道带宽 (Hz)。

- 超过此上限 → **码间串扰**，无法正确识别码元
- 奈氏准则给出了**码元传输速率的上限**，未限制信息传输速率
- 提高信息传输速率：让每个码元携带更多比特

### 3.2 香农公式

有噪声信道中：

$$C = W \times \log_2(1 + \frac{S}{N}) \quad (bit/s)$$

其中：
- C = 信道极限信息传输速率
- W = 信道带宽 (Hz)
- S = 信号平均功率
- N = 噪声功率
- S/N = 信噪比

**信噪比的分贝表示：**
$$信噪比(dB) = 10 \times \log_{10}(\frac{S}{N})$$

例如：S/N=10 → 10dB，S/N=1000 → 30dB

关键结论：
- 带宽或信噪比越大，极限传输速率越高
- 只要传输速率低于极限值，就一定存在无差错传输的方法
- **香农公式给出了绝对的极限，无论多复杂的编码都无法突破**

### 3.3 奈氏准则 vs 香农公式的意义

- 奈氏准则：**激励**工程师探索更先进的编码技术
- 香农公式：**告诫**工程师存在不可突破的绝对极限

## 4. 传输媒体

### 4.1 导引型传输媒体

**双绞线**：
- 两根绝缘铜导线绞合而成，绞合度越高传输率越高
- UTP（无屏蔽）vs STP（屏蔽）
- 常用类别：

| 类别 | 带宽 | 典型应用 |
|------|------|--------|
| 3类 | 16 MHz | 10 Mbit/s 以太网 |
| 5类 | 100 MHz | 100 Mbit/s |
| 超5类(5E) | 125 MHz | 1 Gbit/s |
| 6类 | 250 MHz | 10 Gbit/s (35~55m) |
| 6A | 500 MHz | 10 Gbit/s (100m) |
| 7类 | 600 MHz | 超过 10 Gbit/s (必须屏蔽) |
| 8类 | 2000 MHz | 25/40 Gbit/s (30m) |

**同轴电缆**：抗干扰好，传输较高速率数据。

**光纤**：
- 通过传递光脉冲通信，传输带宽极大
- 多模光纤：多条光线传输，近距离（约2km），便宜
- 单模光纤：直径仅几个微米，远距离，昂贵
- 工作波段：850nm, 1300nm, 1550nm
- 优点：通信容量大、损耗小、抗电磁干扰、保密性好、体积小重量轻

### 4.2 非导引型传输媒体（无线）

**微波通信**：
- 频率 300MHz~300GHz，主要使用 2~40GHz
- 直线传播，一般 50km 左右
- 远距离需**微波接力**（中继站）
- 多径效应：多条路径到达叠加产生失真

**卫星通信**：
- 传播时延大：250~300ms
- 通信费用与距离无关
- 低轨道卫星（2000km以下）已开始使用

**ISM频段**：可自由使用的无线电频段（无线局域网使用）

## 5. 信道复用技术 ⭐⭐

### 5.1 频分复用 FDM

- 将整个带宽分为多份
- 各用户始终占用各自的**频带**
- 所有用户在**同一时间**占用**不同频带**

### 5.2 时分复用 TDM

- 时间划分为等长的**时分复用帧（TDM帧）**
- 每用户在 TDM 帧中占用**固定序号的时隙**
- 所有用户在**不同时间**占用**相同频带**
- 缺点：信道利用率可能不高（用户无数据时，时隙也被浪费）

### 5.3 统计时分复用 STDM

- 按需**动态**分配时隙
- 不是固定分配，提高线路利用率
- STDM 帧中的时隙数小于连接的用户数

### 5.4 波分复用 WDM

- 光的频分复用
- 一根光纤同时传输多个不同波长的光载波信号

### 5.5 码分复用 CDM / 码分多址 CDMA ⭐⭐⭐

**核心特点**：各用户使用**不同码型**，可以在**同一时间同一频带**通信，不会造成干扰。

#### CDMA 工作原理

每个比特时间划分为 m 个短间隔，称为**码片** (chip)。

- 每个站分配一个唯一的 m bit 码片序列
- 发送比特 1 → 发送自己的码片序列
- 发送比特 0 → 发送码片序列的**二进制反码**
- 实际发送数据率 = b × m bit/s，占用的频带宽度也提高到 m 倍（**扩频**）

#### 码片序列的正交性

令向量 S 表示站 S 的码片序列，T 表示站 T 的码片序列。

**规格化内积：**  $S \cdot T = \frac{1}{m}\sum_{i=1}^{m} S_i \times T_i$

正交关系：
- $S \cdot T = 0$ （S 和 T 正交）
- $S \cdot S = 1$ （自身内积为1）
- $S \cdot \bar{S} = -1$ （与反码内积为-1）

> 用 +1 和 -1 分别表示二进制 1 和 0。

#### CDMA 收发过程

**发送端**：
```
S站发送数据 = S要发送的比特 × S的码片序列
T站发送数据 = T要发送的比特 × T的码片序列
总信号 = S站信号 + T站信号
```

**接收端**：用 S 的码片序列对总信号做规格化内积
- 得到 +1 → S 发送了比特 1
- 得到 -1 → S 发送了比特 0
- 得到 0 → S 没有发送数据（或与其他站正交）

#### CDMA 例题

```
S站 8位码片序列：(-1 -1 -1 +1 +1 -1 +1 +1)
即二进制：00011011

S发1 → 发送 00011011
S发0 → 发送 11100100
```

## 7. 宽带接入技术（了解）

**ADSL**（非对称数字用户线）：
- 利用现有电话线（铜线），不需要重新布线
- 不对称：下行带宽 >> 上行带宽
- 使用 DMT 调制技术（频分复用）

**HFC**（光纤同轴混合网）：
- 基于有线电视网改造，主干用光纤，用户端用同轴电缆

**FTTx**（光纤到...）：
- FTTH（到家）、FTTB（到大楼）、FTTC（到路边）
- 使用 PON（无源光网络）
  - EPON：以太网无源光网络
  - GPON：吉比特无源光网络
