## 必考大题预测

1. **CRC 循环冗余校验**（第3章，8分）— 计算发送数据，注意加 n 个 0
2. **IP 地址/子网划分/CIDR**（第4章，8分）— 划分子网/路由聚合
3. **TCP 拥塞控制**（第5章，8分）— 慢开始/拥塞避免/快重传/快恢复
4. **IP 数据报分片** 或 **首部检验和**（第4章，8分）
5. **综合性题目**（可能融合多章知识点）

## 复习策略

1. **第一轮**：逐章阅读详细复习文件，理解概念
2. **第二轮**：重做所有作业题，特别注意计算题
3. **第三轮**：看速查表 + 查漏补缺
4. **考前**：只看速查表
