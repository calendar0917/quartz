## 数据声明
符号系统的创建：形式 -> 内容

起手式：定义数据类型(ID)
- 功能 = 数据类型的排列组合
- 数据类型 = 程序的**有限**边界

现代软件开发：声明类型，而不要写文档、注释

Id = identity --> `A = A`
- 与 name 相比，更形式化，适合做计算，但用户体验较差

时间
- 要用 utc number 存储

空间
- 暂时还没有统一的标记方式
- adm1 省级行政区
- adm2 市级行政区

内容
- message，数据的自我表达
