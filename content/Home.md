## 短期安排
### 第一阶段：底层重构与突击（12.12 - 12.19）

**核心目标**：拿下《计组》，并通过机考练手《数据结构》。

- **12.12 - 12.18（考前冲刺周）**
    
    - **早晨 (8:00 - 10:00)**：**概率论（强制插入）**。
        
        - 策略：你基础薄弱，不能留到最后。把概率论当成“系统性能分析工具”学。
            
        - 行动：每天只搞懂一个章节的概念，通过刷例题来理解。不要纠结证明，**只看输入（条件）和输出（公式）**。
            
    - **上午 (10:00 - 12:00)**：**计算机组成原理**。
        
        - 工程视角：不要死背。
            
            - **Cache**：结合你写 C 代码时的局部性原理（Locality）思考，为什么链表比数组对 Cache 不友好？
                
            - **流水线**：这是分支预测和 Spectre 漏洞的基础。
                
            - **中断/IO**：结合 Linux 内核的上下文切换（Context Switch）理解。
                
        - 复习：重点看 CPU 指令执行流程（Datapath）和存储器扩展。

			
    - **下午 (14:00 - 17:00)**：**数据结构（机考准备）**。
        
        - 策略：你是 Arch 用户，不要用残废的 IDE。在 Neovim 里手写核心代码：链表反转、二叉树遍历（递归+非递归）、图的搜索（DFS/BFS）、最短路径（Dijkstra）。
            
        - 行动：去 LeetCode 找对应 Tag，或者把书上的伪代码用 C 实现一遍，必须跑通。
            
    - **晚上 (19:00 - 22:00)**：**计组刷题 & 物理（微量）**。
        
        - 刷往年计组试卷。最后 30 分钟看一眼大物公式，仅仅是混个眼熟。
            
- **12.19（计组日）**
    
    - 上午：过一遍错题。
        
    - **14:00 - 16:00：考试**。
        
    - 考完当晚：**立即切换**。复习密码学 Presentation。

### 第二阶段：中间件与协议层（12.20 - 12.26）

**核心目标**：通过 DS 机考，低成本拿下 C++ 和密码学。

- **12.20（Pre 日）**
    
    - 搞定 Pre。晚上开始高强度复习数据结构机考。
        
- **12.21 - 12.23（DS 机考冲刺）**
    
    - **数据结构**：
        
        - 深度：从内存布局角度理解。Struct 的内存对齐（Padding）对结构体大小的影响？指针本质就是虚拟地址。
            
        - 算法：重点复习排序（快排、堆排）和查找。
            
    - **12.23 考完后**：当晚开始看 C++。
        
- **12.24 - 12.25（C++ 突击）**
    
    - 策略：你已有 C/Java 基础，C++ 只是语法糖和内存模型的结合。
        
    - 工程视角（必考点 & 以后 Pwn 的基础）：
        
        - **虚函数表 (vtable)**：这是 C++ 多态的核心，也是堆溢出攻击的重点。搞懂对象在内存里长什么样。
            
        - **RAII & 智能指针**：理解 std::shared_ptr 的引用计数，对比 Java 的 GC。
            
        - **STL**：std::vector 的扩容机制（1.5倍还是2倍？），迭代器失效问题。
            
    - **12.25 14:00 考试**。
        
- **12.26（密码学突击）**
    
    - 策略：你上课听了，这是长板。
        
    - 复习：AES 的 S-box (置换混淆)，RSA 的数论基础（欧拉定理），ECC（椭圆曲线）。
        
    - 工程视角：不要只背数学。思考**侧信道攻击**（Side-channel attack），为什么实现加密算法时要通过常量时间（Constant-time）执行来防止时序攻击？
        
    - **14:00 考试**。

### 第三阶段：高维数学与物理攻坚（12.27 - 1.13）

**核心目标**：攻克“短板”。这是决定满绩与否的关键。

- **12.27 - 12.31（数据结构笔试周）**
    
    - 重心回到**数据结构笔试**。
        
    - 策略：笔试和机考不同，更偏向理论复杂度分析和手写代码逻辑。
        
    - 行动：每天 2 小时给**概率论**，剩下全给 DS。
        
    - **12.31 14:00 考试**。
        
- **1.1 - 1.5（概率论：生死战）**
    
    - 现状：薄弱，作业抄的。
        
    - 战术：**逆向工程**。
        
        1. **放弃严谨推导**：你不需要知道“为什么”，只需要知道“怎么算”。把概率论看作是一门“API 调用”课程。
            
        2. **核心模块**：
            
            - 贝叶斯公式（必考，把它当做信息修正模型）。
                
            - 常见分布（正态、泊松、二项）：背下它们的 PDF、期望、方差公式。
                
            - 大数定律与中心极限定理：直观理解即可。
                
        3. **刷题**：直接拿往年卷子和课后题，对着答案逆推解题步骤。死记硬背解题 Pattern。
            
    - **1.5 14:00 考试**。
        
- **1.6 - 1.13（大物：最后的高地）**
    
    - 现状：没听，物理直觉弱。
        
    - 战术：**降维打击**。
        
    - **电磁学**：这是重点。把它映射到电子专业：
        
        - 麦克斯韦方程组 -> 无线电通信的基础。
            
        - 电容/电感 -> 滤波电路、电源纹波。
            
    - **刷题策略**：大物通常题库重复率高。
        
        - Action：搞到学校的“大物题库”或往年真题。
            
        - 背典型物理模型（刚体转动、简谐振动、高斯定理应用）。
            
    - **1.13 9:30 考试**。
