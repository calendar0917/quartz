## 一、对数运算

### 1.1 基本性质
| 性质 | 公式 |
|------|------|
| 乘法 | $\log(xy) = \log x + \log y$ |
| 除法 | $\log(x/y) = \log x - \log y$ |
| 幂 | $\log(x^n) = n \log x$ |
| 换底 | $\log_a x = \log_b x / \log_b a$ |

### 1.2 信息论中的三种底数
| 底数 | 单位 | 缩写 | 关系 |
|------|------|------|------|
| 2 | 比特(bit) | bit | 1 bit $\approx$ 0.693 nat $\approx$ 0.301 Hart |
| e | 奈特(nat) | nat | 1 nat $\approx$ 1.443 bit |
| 10 | 笛特/哈特(Hart) | Hart | 1 Hart $\approx$ 3.322 bit |

### 1.3 重要结论
- $\log_e(x) = \ln x$，通常用 $\ln x$ 记为 $\log_e x$
- $\ln x \le x - 1$（$x > 0$），等号当且仅当 $x = 1$——最大熵定理证明核心
- $\lim_{\varepsilon \to 0} \varepsilon \cdot \log \varepsilon = 0$——扩展性证明用
- $-p \log p - (1-p) \log (1-p)$ 记作 $H(p)$，称为**二元熵函数**

## 二、概率论基础

### 2.1 基本关系
| 关系 | 公式 |
|------|------|
| 条件概率 | $p(a_i \mid b_j) = p(a_i b_j) / p(b_j)$ |
| 乘法公式 | $p(a_i b_j) = p(a_i) \cdot p(b_j \mid a_i) = p(b_j) \cdot p(a_i \mid b_j)$ |
| 全概率 | $p(b_j) = \sum_i p(a_i) \cdot p(b_j \mid a_i)$ |
| 贝叶斯 | $p(a_i \mid b_j) = p(a_i) p(b_j \mid a_i) / p(b_j)$ |
| 独立性 | $X \perp Y \Leftrightarrow p(a_i b_j) = p(a_i) \cdot p(b_j)$ |

### 2.2 归一化条件
- $\sum_i p(a_i) = 1$（所有概率之和为1）
- $\sum_j p(b_j \mid a_i) = 1$（条件概率对条件求和为1）
- $\sum_i \sum_j p(a_i b_j) = 1$

### 2.3 数学期望
- $E[X] = \sum_i x_i \cdot p(x_i)$
- 信息论中熵 $H(X) = E[I(a_i)] = E[-\log p(a_i)]$

### 2.4 方差（自信息量方差）
- $\sigma^2 = E[I^2(a_i)] - H^2(X)$
- 用于定长编码定理计算所需序列长度

## 三、线性代数基础

### 3.1 GF(2) 域（二元域）运算
| 运算 | 规则 |
|------|------|
| 加法 $\oplus$ | $0 \oplus 0 = 0$，$0 \oplus 1 = 1$，$1 \oplus 0 = 1$，$1 \oplus 1 = 0$（异或） |
| 乘法 $\cdot$ | $0 \cdot 0 = 0$，$0 \cdot 1 = 0$，$1 \cdot 0 = 0$，$1 \cdot 1 = 1$（与） |

减法等同加法：$a - b = a \oplus b$

### 3.2 矩阵运算（GF(2)）
- 矩阵乘法：行 $\times$ 列，逐元素乘加后模2
- 转置：交换行列
- 初等行变换：行交换、行 $\oplus$ 行（模2）

### 3.3 生成矩阵与校验矩阵
- 生成矩阵 $G$：$k \times n$，秩为 $k$
- 校验矩阵 $H$：$(n-k) \times n$，秩为 $n-k$
- 核心关系：**$G \cdot H^T = 0$**（$k \times (n-k)$ 零矩阵）

### 3.4 系统码矩阵形式
$$
\begin{aligned}
G_s &= [I_k \mid Q] \quad (k \times n) \\
H_s &= [Q^T \mid I_{n-k}] \quad ((n-k) \times n)
\end{aligned}
$$

## 四、多项式运算（GF(2)）

### 4.1 基本概念
- $c(x) = c_{n-1}x^{n-1} + \dots + c_1 x + c_0$
- 多项式次数 $\partial c(x)$：最高非零项幂次
- 首一多项式：最高次项系数为1

### 4.2 模运算
- $c(x) = m(x) \bmod g(x)$：$c(x)$ 除以 $g(x)$ 的余式
- 加减法：系数模2（异或）
- 乘法：多步异或

### 4.3 因式分解（$n = 7$ 时的关键分解）
$$
x^7 - 1 = (x + 1)(x^3 + x^2 + 1)(x^3 + x + 1) \quad [\mathrm{GF}(2)]
$$
此分解用于构造 $(7,4)$ 和 $(7,3)$ 循环码。

### 4.4 多项式循环移位
$$
c^{(i)}(x) = x^i \cdot c(x) \bmod (x^n - 1)
$$

## 五、拉格朗日乘子法

### 5.1 基本思路
求 $f(x)$ 在约束 $g(x) = C$ 下的极值，构造：
$$
F(x, \lambda) = f(x) + \lambda(g(x) - C)
$$
令 $\partial F / \partial x = 0$，$\partial F / \partial \lambda = 0$ 求解。

### 5.2 在信息论中的应用
- 求信道容量：$\max I(X;Y)$ 约束 $\sum p(a_i) = 1$
- 求率失真函数：$\min I(X;Y)$ 约束 $\bar{D} \le D$ 和 $\sum p(b_j \mid a_i) = 1$
