## 一、知识框架

```
信源 X → [试验信道 P(Y|X)] → 输出 Y
                ↓
失真函数 d(a_i,b_j) → 平均失真度 D̄ = ΣΣ p(a_i)p(b_j|a_i)d(a_i,b_j)
                ↓
保真度准则：D̄ ≤ D → 试验信道集合 P_D
                ↓
信息率失真函数：R(D) = min I(X;Y)（在 P_D 中寻找最小 I(X;Y)）
                ↓
             ┌────┴────┐
             ↓         ↓
         R(D)的性质   二元/等概率 R(D) 计算
             ↓
        信息价值 V = D_max - D(R)
```

---

## 二、核心知识点

### 2.1 失真函数与平均失真度

**失真函数 d(a_i, b_j)：** 用 b_j 代替 a_i 引起的失真。非负函数。

**失真矩阵 D：**
```
      b₁     b₂    ...   b_m
a₁ [d(a₁,b₁) d(a₁,b₂) ... d(a₁,b_m)]
a₂ [d(a₂,b₁) d(a₂,b₂) ... d(a₂,b_m)]
...
a_n [d(a_n,b₁) d(a_n,b₂) ... d(a_n,b_m)]
```

**常见失真函数：**

**(1) 汉明失真：**
```
d(a_i, b_j) = { 0  i = j
              { α  i ≠ j  (α>0，通常α=1)
```

**(2) 平方误差失真：**
```
d(a_i, b_j) = (b_j - a_i)²
```

**平均失真度：**
```
D̄ = ΣΣ p(a_i)·p(b_j|a_i)·d(a_i, b_j)
```

**保真度准则：** D̄ ≤ D（允许的失真上限）

**N次扩展：** D̄(N) = N·D̄，保真度准则 D̄(N) ≤ N·D

### 2.2 信息率失真函数 R(D) 的定义 ⭐

将信源编码器看作"假想信道"，选择 p(b_j|a_i) 使：
```
R(D) = min I(X;Y)
       p(b_j|a_i) ∈ P_D
```
其中 P_D = {p(b_j|a_i) : D̄ ≤ D}。

**物理意义：** 在允许失真不超过 D 的条件下，信源必须传送的最小信息率。

### 2.3 R(D) 的性质

**(1) 定义域：** [0, D_max]
- D = 0 时：R(0) = H(X)（离散信源）
- D ≥ D_max 时：R(D) = 0

**D_max 的计算：**
```
D_j = Σ_i p(a_i)·d(a_i, b_j)
D_max = min_j D_j
```

**(2) 下凸性：**
```
R(θD' + (1-θ)D'') ≤ θR(D') + (1-θ)R(D'')
```
即 R(D) 是 D 的下凸（∪形）函数。

**(3) 单调递减和连续性：** R(D) 随 D 增大单调递减。

> **R(D) 曲线特征：**
> D=0: R=H(X)（最高点）
> D↑: R 单调下降
> D≥D_max: R=0（水平线）
> 形状：下凸

### 2.4 离散信源 R(D) 的参量表达式（不要求计算，但要理解）

引入参数 S (S<0) 和 λ_i，利用拉格朗日乘子法得：
```
p(b_j|a_i) = λ_i·p(b_j)·e^{S·d(a_i,b_j)}
```
并有 dR/dD = S。

### 2.5 二元及等概率离散信源的 R(D) [必会计算！] ⭐⭐

**设二元信源：**
```
X = {a₁(p), a₂(1-p)}，p ≤ 1/2
汉明失真矩阵：d(a_i,b_j) = {0 i=j; α i≠j}
```

**则 D_max = α·p**（因为 D₁=(1-p)α, D₂=pα，p≤1/2时D₂最小）

**R(D) 公式（汉明失真 α）：**
```
R(D) = H(p) - H(D/α)
     = H(p) - [-(D/α)log(D/α) - (1-D/α)log(1-D/α)]
```
其中 H(x) = -x log x - (1-x) log(1-x) 是二元熵函数。

> **特例：p=0.5（等概率二元信源），α=1：**
> D_max = 0.5
> R(D) = 1 - H(D)  (0 ≤ D ≤ 0.5)

**计算步骤模板：**
```
1. 确定信源分布 p(a_i)
2. 确定失真函数 d(a_i,b_j)，α 的值
3. 计算 D_max = min_j Σ_i p(a_i)·d(a_i,b_j) = α·p（汉明失真时）
4. 代入公式 R(D) = H(p) - H(D/α)
5. 验证：D=0时 R=H(p), D=D_max时 R=0
```

### 2.6 信息价值

**信息价值：** `V = D_max - D(R)`

物理意义：信息率为 R 时，比完全不传送信息减少的损失。

**价值率：** `dV/dR = -D'(R) = -1/S`

> **例7.4（产品质量检验）：**
> 合格品 a₁(p=0.99)，废品 a₂(p=0.01)
> d(a₁,b₂)=1（合格品报废损失），d(a₂,b₁)=100（废品出厂损失）
> D_max = 0.99 元/件
> 检验不完全可靠时 D̄=0.199 元，I(X;Y)=0.025 bit
> 价值率 = (0.99-0.199)/0.025 = 31.6 元/bit

### 2.7 信道容量 C 与率失真函数 R(D) 对比 [必考问答题！] ⭐

| 比较项 | 信道容量 C | 率失真函数 R(D) |
|--------|-----------|----------------|
| 数学本质 | I(X;Y)的极大值 | I(X;Y)的条件极小值 |
| 凸性 | I(X;Y)对p(a_i)上凸 | I(X;Y)对p(b_j\|a_i)下凸 |
| 自变量 | 信源分布 p(a_i) | 信道转移概率 p(b_j\|a_i) |
| 决定因素 | 仅与信道特性有关 | 仅与信源特性有关 |
| 解决的问题 | 可靠性问题 | 有效性问题 |
| 工程应用 | 信息传输基础 | 信源压缩基础 |
| 核心思想 | 给定信道，最大能传多少 | 给定失真，最少需要多少 |

> **记忆口诀：** C看信道求极大，R看信源求极小；C定传输上界，R定压缩下界。

## 四、常见易错点

1. **R(D) 是求 I(X;Y) 的最小值，不是最大值！**（与 C 相反）
2. 试验信道 P_D 是"假想信道"——实际上信源编码器不是真的信道
3. R(0) = H(X) 仅对离散信源成立（连续信源 R(0)→∞）
4. D_max 的计算：取所有 D_j 的**最小值**，不是最大值
5. 二元信源汉明失真时 D_max = α·min(p, 1-p)
6. R(D) 与 C 的凸性容易搞混：C是上凸(∩)，R(D)是下凸(∪)
