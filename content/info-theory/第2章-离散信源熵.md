```
单符号离散信源的数学模型 → 自信息量 → 信源熵 H(X)
                           ↓
                      条件自信息量 → 条件熵 H(X|Y)
```

## 二、核心知识点

### 2.1 单符号离散信源的数学模型

信源 X 取值于 {a₁, a₂, ..., a_n}，概率分布：

```
        [ a₁   a₂   ...  a_i  ...  a_n ]
X:      [ p(a₁) p(a₂) ... p(a_i) ... p(a_n) ]
```

约束：`0 ≤ p(a_i) ≤ 1`，`Σ p(a_i) = 1`

### 2.2 自信息量

**定义：** `I(a_i) = -log p(a_i) = log(1/p(a_i))`

**物理意义：** 随机事件 a_i 发生所带来的信息量。概率越小，信息量越大。

**性质：**
1. 非负性：I(a_i) ≥ 0
2. p(a_i)=1 时 I(a_i)=0（必然事件无信息）
3. p(a_i)→0 时 I(a_i)→∞
4. I(a_i) 是 p(a_i) 的单调递减函数
5. **I(a_i) 是随机变量**（随 a_i 变化）

**单位：** 以2为底→bit，以e为底→nat，以10为底→Hart

> **等概率二进制码元：** p(0)=p(1)=1/2 时，I(0)=I(1)=log₂2=1 bit

**联合自信息量：** `I(a_i b_j) = -log p(a_i b_j)`
- 当 X、Y 独立时：I(a_i b_j) = I(a_i) + I(b_j)

**条件自信息量：** `I(a_i|b_j) = -log p(a_i|b_j)`

**三者关系：** `I(a_i b_j) = I(a_i) + I(b_j|a_i) = I(b_j) + I(a_i|b_j)`

### 2.3 信源熵

**定义：** `H(X) = E[I(a_i)] = -Σ p(a_i) log p(a_i)`

**物理含义：**
1. 信源输出后，平均每个消息提供的信息量
2. 信源输出前，信源的平均不确定度
3. 反映了变量 X 的随机性

**单位：** bit/sign（比特/符号）

> **例2.2.2 天气信源：** X={晴(1/2), 阴(1/4), 雨(1/8), 雪(1/8)}
> H(X) = -½log½ - ¼log¼ - ⅛log⅛ - ⅛log⅛ = 1.75 bit/sign

**条件熵：**
```
H(Y|X) = E[I(b_j|a_i)] = -ΣΣ p(a_i b_j) log p(b_j|a_i)
```
物理意义：已知 X 后，Y 还剩下的平均不确定度。

**联合熵：**
```
H(XY) = E[I(a_i b_j)] = -ΣΣ p(a_i b_j) log p(a_i b_j)
```
物理意义：X 和 Y 同时发生时的总平均不确定度。

**熵之间的关系（核心！）：**
```
H(XY) = H(X) + H(Y|X) = H(Y) + H(X|Y)
```
- 当 X、Y 独立时：H(XY) = H(X) + H(Y)，H(Y|X) = H(Y)

### 2.4 信源熵的8个性质及证明

#### (1) 非负性
`H(X) ≥ 0`

因为 0 ≤ p(a_i) ≤ 1，所以 -log p(a_i) ≥ 0。

#### (2) 对称性
`H(p₁, p₂, ..., p_n) = H(p₂, p₁, ..., p_n)`

熵只与概率的数值有关，与消息的顺序无关。

#### (3) 最大离散熵定理 ⭐【必会证明】
`H(X) ≤ log n`，等号当且仅当所有 p(a_i) = 1/n 时成立。

> **证明：**
> 利用 ln x ≤ x-1（x>0，等号当 x=1）
>
> H(X) - log n = Σ p_i log(1/p_i) - Σ p_i log n
> = Σ p_i log(1/(np_i))
> = Σ p_i · ln(1/(np_i)) · log e
> ≤ Σ p_i · (1/(np_i) - 1) · log e    [用 ln x ≤ x-1，x = 1/(np_i)]
> = Σ (1/n - p_i) log e
> = (1 - 1) log e = 0
>
> 故 H(X) ≤ log n。等号当仅当 1/(np_i) = 1，即 p_i = 1/n，等概率。

#### (4) 扩展性
`lim_{ε→0} H(p₁, ..., p_n, ε) = H(p₁, ..., p_n)`

小概率事件对熵的贡献趋近于0（因为 lim_{ε→0} ε log ε = 0）。

#### (5) 确定性
`H(1, 0) = H(1, 0, 0, ..., 0) = 0`

只要有一个概率为1，其余为0，熵为0（完全确定）。

#### (6) 可加性
`H(XY) = H(X) + H(Y|X)`

这是熵函数形式的唯一性保证。

#### (7) 极值性
`H(X|Y) ≤ H(X)`

已知 Y 后，关于 X 的不确定度不会增加，只会减少或不变。

#### (8) 上凸性
`H(αP + (1-α)Q) ≥ αH(P) + (1-α)H(Q)`，0≤α≤1

熵函数是概率分布的上凸（凹）函数，极值必为极大值。

> **一般二元信源熵：**
> H(X) = -[p log p + (1-p) log(1-p)]
> p=0.5 时取最大值 1 bit，p=0 或 1 时取最小值 0。

### 2.5 冗余度与信息变差

**信源实际熵 H_∞**：考虑符号间关联后的极限熵。

**最大熵 H₀** = log n（等概率无关联时）。

**相对率：** `η = H_∞ / H₀`

**冗余度：** `ξ = 1 - η = (H₀ - H_∞) / H₀`

**信息变差：** `I_0∞ = H₀ - H_∞`

> **英语信源：** H₀=log₂27=4.76, H₁≈4.03, H₂≈3.32, H₃≈3.1, H_∞≈1.4
> 英语冗余度 ξ ≈ 0.71

## 三、习题

### 课件练习（选择题）

**Q1.** 一个随机事件发生某一结果后所带来的信息量称____。
A. 信息熵  B. 自信息量  C. 互信息量  D. 信道容量
> **答案：B**

**Q2.** 关于自信息量的性质，____的描述是错误的。
A. I(a_i)是非负值  B. I(a_i)是p(a_i)的单调递增函数
C. 当p(a_i)=1时，I(a_i)=0  D. 条件自信息量定义为条件概率对数的负值
> **答案：B**（单调递减，不是递增）

**Q3.** 关于自信息量、条件自信息量、联合自信息量，下列描述错误的是____。
A. I(a_i|b_j) = -log p(a_i|b_j)  B. I(a_i b_j) = -log p(a_i b_j)
C. I(a_i b_j) = I(a_i) + I(b_j)  D. I(a_i b_j) = I(b_j) - I(a_i|b_j)
> **答案：C**（只有独立时才成立）

**Q4.** 下列不是信源熵的基本性质的是____。
A. 对称性  B. 确定性  C. 极值性  D. 下凸性
> **答案：D**（熵是上凸函数）

**Q5.** 下列关于各种熵之间的关系描述中，错误的是____。
A. H(X)=H(XY)-H(Y|X)  B. H(Y|X)≤H(X)
C. H(X)≥0  D. H(X|Y)=H(X)+H(Y)
> **答案：D**

**Q6.** 当信源X中包含n个不同离散消息时，信源熵H(X)有____。
A. H(X)＜log n  B. H(X)≤log n  C. H(X)＞log n  D. H(X)≥log n
> **答案：B**（最大离散熵定理）

### 课件例题

**例2.2.1（自信息量计算）**
某地二月天气：晴(1/2), 阴(1/4), 雨(1/8), 雪(1/8)。求各天气的自信息量。

> 解：I(晴) = -log₂(1/2) = 1 bit
> I(阴) = -log₂(1/4) = 2 bit
> I(雨) = -log₂(1/8) = 3 bit
> I(雪) = -log₂(1/8) = 3 bit

**例2.2.2（信源熵计算）**
同上天气信源，求信源熵。

> 解：H(X) = -½log₂½ - ¼log₂¼ - ⅛log₂⅛ - ⅛log₂⅛
> = ½×1 + ¼×2 + ⅛×3 + ⅛×3 = 1.75 bit/sign

## 四、常见易错点

1. **自信息量是随机变量**，信源熵是数学期望（定值）
2. H(X) 和 I(a_i) 的区别：前者是平均量（定值），后者是针对单个事件的随机量
3. 独立时 H(Y|X)=H(Y)（不等于0！）
4. 熵的上凸性 vs. 互信息的上/下凸性（第4章混在一起容易搞混）
5. H(X)=0 不代表无信息（p(a_i)=1时确实无不确定度）
