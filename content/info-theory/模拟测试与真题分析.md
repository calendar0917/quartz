## 三、课件未详细覆盖但真题必考的知识

### 3.1 连续信源最大熵定理 ⭐

**限峰值功率（取值范围[a,b]）：** 均匀分布时熵最大
```
H_c(X) = log₂(b - a)    bit/符号
```

**限平均功率（方差≤σ²，均值=0）：** 高斯分布时熵最大
```
H_c(X) = 0.5·log₂(2πeσ²)    bit/符号
```

### 3.2 连续信道——香农公式 ⭐

**带宽为 W 的连续信道，噪声为高斯白噪声：**
```
C = W · log₂(1 + S/N)    bit/s
```
- S/N ≥ 0 为信噪比（功率比，非dB）
- S/N(dB) = 10·log₁₀(S/N)

**典型计算流程：**
```
1. 算信息总量 I_total = 像素数 × 每像素bit数 × 帧数
2. 求信道容量 C = I_total / 时间
3. 代香农公式求 W 或 S/N
```

### 3.3 马尔科夫信源极限熵 ⭐⭐

**一阶马尔科夫信源：**
```
H_∞ = H(X₂|X₁) = -Σ p(s_i) Σ p(s_j|s_i) log p(s_j|s_i)
```
1. 先求平稳分布概率 p(s_i)：解方程组 p = p·P，Σ p(s_i) = 1
2. 再求条件熵 H_∞ = Σ p(s_i)·H(X|s_i)

### 3.4 一页开卷必备公式单（浓缩版）

```
═══ 熵 ═══
H(X) = -Σ p(a_i)log₂p(a_i)
H(XY) = H(X) + H(Y|X) = H(Y) + H(X|Y)
I(X;Y) = H(X) - H(X|Y) = H(X) + H(Y) - H(XY)
H(X²) = 2H(X), H(X³) = 3H(X)  [无记忆扩展]

═══ 互信息 ═══
I(a_i;b_j) = log₂[p(a_i b_j)/(p(a_i)p(b_j))]
I(X;Y) = ΣΣ p(a_i b_j) log₂[p(b_j|a_i)/p(b_j)]

═══ 信道容量 ═══
C = max I(X;Y)
对称信道: C = log₂m - H(行元素)
强对称: C = log₂n - H(p) - p·log₂(n-1)  [n=m时]
二进制均匀: C = 1 - H(p)
连续高斯: C = W·log₂(1+S/N)

═══ 率失真 ═══
二元汉明失真: R(D) = H(p) - H(D/α)  (α=1时 D∈[0,p])
等概率n元汉明失真: R(D) = log₂n - H(D) - D·log₂(n-1)
D_max = α·min(p, 1-p)

═══ 编码 ═══
K̄ = Σ p_i·k_i, η = H(X)/K̄, R = K̄·log₂m
Claft: Σ m^{-k_i} ≤ 1

═══ 纠错码 ═══
c = mG, s = rHᵀ, G·Hᵀ = 0
d_min = min w(c≠0)
l = d_min-1 可检, t = ⌊(d_min-1)/2⌋ 可纠
循环码: c(x)=m(x)g(x), g(x)|(xⁿ-1)
系统循环码: c(x) = x^{n-k}m(x) + [x^{n-k}m(x) mod g(x)]

═══ 密码 ═══
完善保密性: I(P;C)=0, H(K)≥H(P)
唯一解距离: V ≈ H(K)/I_0∞
```
