## 熵
```
H(X) = -Σ p(a_i) log₂ p(a_i)
H(XY) = -ΣΣ p(a_i b_j) log₂ p(a_i b_j) = H(X) + H(Y|X) = H(Y) + H(X|Y)
H(Y|X) = -ΣΣ p(a_i b_j) log₂ p(b_j|a_i) = H(XY) - H(X)
I(X;Y) = ΣΣ p(a_i b_j) log₂[p(a_i b_j)/(p(a_i)p(b_j))] = H(X) - H(X|Y) = H(X) + H(Y) - H(XY)
H(X²) = 2H(X), H(X³) = 3H(X)  (无记忆扩展)
H(X|Y) ≤ H(X), H(X) ≤ log₂ n   (极值性; 最大熵定理)
H(XY) = H(X) + H(Y)   (X,Y独立时)
熵函数上凸: H(αP+(1-α)Q) ≥ αH(P)+(1-α)H(Q)
连续(限峰值): H_c(X) = log₂(b-a)   (均匀分布最大)
连续(限功率): H_c(X) = ½log₂(2πeσ²)   (高斯分布最大)
```

## 信道容量
```
C = max_{p(a_i)} I(X;Y)
一一对应无噪: C = log₂ n
扩展无噪: C = log₂ n
归并无噪: C = log₂ m
强对称(n=m): C = log₂ n - H(p) - p·log₂(n-1)
对称信道: C = log₂ m - H(行元素)
二进制均匀: C = 1 - H(p)
连续高斯: C = W·log₂(1 + S/N)    [S/N为功率比]
S/N(dB) = 10·log₁₀(S/N), S/N = 10^{dB/10}
有噪编码定理: R<C→L足够大时P_e→0; R>C→P_e>0
```

## 信源编码
```
K̄ = Σ p(a_i)·k_i
η = H(X)/K̄ (二元时 R=K̄)
香农码: k_i = ⌈-log₂p(a_i)⌉, 码字=累加概率p_a的二进制前k_i位
费诺码: 按概率等分→递归分配码元
赫夫曼码: 概率排序→合并最小两个→反向读码字
克拉夫特不等式: Σ m^{-k_i} ≤ 1  (即时码充要条件)
```

## 率失真函数
```
D̄ = ΣΣ p(a_i)p(b_j|a_i)d(a_i,b_j)
R(D) = min I(X;Y)  s.t. D̄ ≤ D    [注意是min不是max!]
R(D)下凸, 单调递减, 定义域[0, D_max]
D_max = min_j Σ p(a_i)d(a_i,b_j)
二元汉明失真(α): R(D) = H(p) - H(D/α), D_max = α·min(p,1-p)
等概率n元汉明: R(D) = log₂n - H(D) - D·log₂(n-1), D_max = (n-1)/n
信息价值: V = D_max - D(R)
```

## 纠错编码
```
c = m·G    (编码),  s = r·Hᵀ    (伴随式)
G·Hᵀ = 0   (k×(n-k)零矩阵)
系统码: G_s = [I_k|Q], H_s = [Qᵀ|I_{n-k}]
d_min = min w(c≠0)   (非零码字)
检错: l = d_min-1,  纠错: t = ⌊(d_min-1)/2⌋
汉明码: n=2^r-1, k=2^r-r-1, d_min=3, t=1
循环码: c(x)=m(x)g(x), g(x)|xⁿ-1, ∂g(x)=n-k
h(x) = (xⁿ-1)/g(x)  (校验多项式)
系统循环码: c(x)=x^{n-k}m(x)+[x^{n-k}m(x) mod g(x)]
伴随多项式: s(x) = r(x) mod g(x)
x⁷-1 = (x+1)(x³+x²+1)(x³+x+1)   [GF(2)]
```

唯一解距离: V ≈ H(K)/I_0∞, I_0∞=H₀-H₁

## 马尔科夫信源
```
平稳分布: p = p·P, Σp_i=1  (解方程组)

```

## C vs R(D)
```
C=max I(X;Y), 上凸, 对p(a_i), 仅与信道有关, 解决可靠性, 传输上界
R(D)=min I(X;Y), 下凸, 对p(b_j|a_i), 仅与信源有关, 解决有效性, 压缩下界
成功通信条件: R(D) ≤ R ≤ C
```

## 定理简述
```
香农第一定理(无失真编码): R>H(X)→L足够大可无失真
香农第二定理(有噪编码): R<C→L足够大时P_e→0
香农第三定理(限失真编码): R>R(D)→L足够大时D̄≤D+ε
最大离散熵定理: 等概时熵最大, H(X)≤log₂n
```
