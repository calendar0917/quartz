## 一、知识框架

```
通信系统：X → [信道 P(Y|X)] → Y
                ↓
互信息量 I(a_i;b_j) → 平均互信息量 I(X;Y)
                ↓
    I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X)+H(Y)-H(XY)
                ↓
信道容量 C = max I(X;Y)
         p(a_i)
                ↓
  ┌─────────┬─────────┬──────────┬──────────┐
  ↓         ↓         ↓          ↓          ↓
无噪信道  强对称   对称信道   准对称    一般信道
         信道              信道    （拉格朗日法）
```

## 二、核心知识点

### 2.1 单符号离散信道的数学模型

信道由 {X, P(Y|X), Y} 三要素决定：
- X：输入符号集 {a₁, ..., a_n}
- Y：输出符号集 {b₁, ..., b_m}
- **信道转移概率矩阵** P(Y|X)：n行m列，第i行第j列为 p(b_j|a_i)

```
       p(b₁|a₁)  p(b₂|a₁)  ...  p(b_m|a₁)
P =    p(b₁|a₂)  p(b₂|a₂)  ...  p(b_m|a₂)
       ...       ...       ...  ...
       p(b₁|a_n)  p(b₂|a_n)  ...  p(b_m|a_n)
```

约束：每行和为1（Σ_j p(b_j|a_i) = 1）

### 2.2 互信息量

**定义：**
```
I(a_i;b_j) = log [p(a_i b_j) / (p(a_i) p(b_j))]
           = log [p(b_j|a_i) / p(b_j)]
           = log [p(a_i|b_j) / p(a_i)]
```

**物理意义：** 收到 b_j 后获得关于 a_i 的信息量 = 通信前后不确定度之差。

**性质：**
1. 对称性：I(a_i;b_j) = I(b_j;a_i)
2. X与Y独立时：I(a_i;b_j) = 0
3. 互信息量可为正值或负值
4. **I(a_i;b_j) = I(a_i) - I(a_i|b_j)**（自信息量 - 条件自信息量）

**条件互信息量：**
```
I(a_i;b_j|c_k) = log [p(a_i b_j|c_k) / (p(a_i|c_k) p(b_j|c_k))]
```

**三个变量的联合互信息量：**
```
I(a_i;b_j c_k) = I(a_i;b_j) + I(a_i;c_k|b_j)
```

### 2.3 平均互信息量 I(X;Y) ⭐

**定义：**
```
I(X;Y) = E[I(a_i;b_j)] = ΣΣ p(a_i b_j) log [p(a_i b_j) / (p(a_i) p(b_j))]
```

**物理意义（三种等价解释）：**
1. Y 对 X 的平均互信息 = 收到 Y 后 X 不确定度减少的量
2. X 对 Y 的平均互信息 = 发送 X 后 Y 不确定度减少的量
3. 通信前后整个系统不确定度减少的量

**核心公式（必须熟记！）：**
```
I(X;Y) = H(X) - H(X|Y)
       = H(Y) - H(Y|X)
       = H(X) + H(Y) - H(XY)
       = I(Y;X)  （对称性）
```

**性质：**
1. **对称性：** I(X;Y) = I(Y;X)
2. **非负性：** I(X;Y) ≥ 0
3. **极值性：** I(X;Y) ≤ H(X)，I(X;Y) ≤ H(Y)
4. **凸函数性：**
   - I(X;Y) 是信源分布 {p(a_i)} 的**上凸函数**（固定信道）
   - I(X;Y) 是信道转移概率 {p(b_j|a_i)} 的**下凸函数**（固定信源）
5. **数据处理定理：** I(X;Z) ≤ I(Y;Z)，I(X;Z) ≤ I(X;Y)
   - 多次处理信息量只减不增！
6. **多次测量：** I(X;Y₁Y₂) ≥ I(X;Y₁)

### 2.4 各种熵之间的关系（必考！）

| 关系式 | 含义 |
|--------|------|
| H(XY) = H(X) + H(Y\|X) | 联合熵的可加性 |
| H(XY) = H(Y) + H(X\|Y) | 同上，反过来 |
| I(X;Y) = H(X) - H(X\|Y) | 互信息=无条件熵-条件熵 |
| I(X;Y) = H(Y) - H(Y\|X) | 同上 |
| I(X;Y) = H(X) + H(Y) - H(XY) | 互信息与联合熵 |
| H(X\|Y) ≤ H(X) | 条件熵不大于无条件熵 |

**熵的文氏图（记住！）：**
```
   ┌──────────────┐
   │  H(X)        │
   │  ┌──────┐    │
   │  │I(X;Y)│    │  H(XY) 是整个圆的外接矩形
   │  └──────┘    │
   │        │     │
   └────────┼─────┘
            │  H(Y)
            └─────
```

### 2.5 信道容量的定义

```
C = max I(X;Y)
     p(a_i)
```

**物理意义：** 信道能够传送的最大信息率。仅与信道特性有关，与信源无关。

### 2.6 四类特殊信道容量计算公式

#### (1) 无噪信道

| 类型 | 条件 | C |
|------|------|---|
| 一一对应 | H(X\|Y)=0, H(Y\|X)=0 | C = log n |
| 扩展型 | H(X\|Y)=0, H(Y\|X)≠0 | C = log n |
| 归并型 | H(X\|Y)≠0, H(Y\|X)=0 | C = log m |

> 核心思想：无噪时 I(X;Y)=H(X) 或 H(Y)，取可达最大值

#### (2) 强对称离散信道 ⭐

矩阵特点：n=m，对角线为 1-p，非对角线为 p/(n-1)
```
C = log n - H(p) - p·log(n-1)
```
等号在 p(a_i) = 1/n 时取到。

> 特例：**二进制均匀信道**（n=2）：
> C = 1 - H(p) = 1 + p log p + (1-p) log(1-p)

#### (3) 对称离散信道 ⭐

矩阵特点：行可排列 + 列可排列
```
C = log m - H(q₁, q₂, ..., q_m)
```
其中 H(q₁,...,q_m) 是任意一行的元素概率算出的熵。

等号在 p(a_i) = 1/n 时取到。

#### (4) 准对称离散信道 ⭐

矩阵特点：行可排列，列可划分为若干可排列子集
```
C = log m - H(q) - Σ N_k log M_k
```
其中 N_k 是第 k 个子集的输出符号数和，M_k 是子集内元素之和。

> **例4.2.1：** P = [[0.5 0.25 0.125 0.125], [0.25 0.5 0.125 0.125]]
> 划分为子集 {b₁,b₂} 和 {b₃,b₄}
> C = 0.0612 bit/sign（计算需要逐步求解 p(b_j)）

### 2.7 离散信道容量的一般计算方法

用拉格朗日乘子法求解 max I(X;Y) 约束 Σp(a_i)=1。

**步骤：**
1. 由 `Σ_j p(b_j|a_i) log p(b_j|a_i) = Σ_j p(b_j|a_i)·β_j` 求 β_j
2. 由 `C = log Σ 2^{β_j}` 求 C
3. 由 `p(b_j) = 2^{β_j - C}` 求 p(b_j)
4. 由 `p(b_j) = Σ_i p(a_i) p(b_j|a_i)` 求 p(a_i)，验证是否满足概率约束

## 三、习题

### 课件练习（选择题）

**Q1.** 下列关于互信息量的描述中，正确的是____。
A. I(a_i;b_j)≠I(b_j;a_i)  B. 当X和Y相互独立时，互信息量不为0
C. 互信息量具有非负性  D. 互信息量等于自信息量减去条件自信息量
> **答案：D**  I(a_i;b_j) = I(a_i) - I(a_i|b_j)

**Q2.** 下列关于平均互信息量的描述中，正确的是____。
A. 平均互信息量是输入信源概率分布的上凸函数
B. I(X;Y)≥H(X)  C. I(X;Y)≥H(Y)
D. 平均互信息量是信道转移概率分布的上凸函数
> **答案：A**（对信源分布上凸，对信道转移概率下凸）

**Q3.** 下列关于各种熵之间的关系描述中，错误的是____。
A. H(X)=H(XY)-H(Y|X)  B. H(Y|X)=H(XY)-H(X)
C. I(X;Y)=H(X)+H(Y)-H(XY)  D. H(X|Y)=H(X)+H(Y)
> **答案：D**

**Q4.** 下列关于信道容量的描述中，错误的是____。
A. 信道容量是描述信道特性的参量
B. 一一对应无噪信道，C只决定于输出符号数m
C. 归并性能无噪信道，C只决定于输出符号数m
D. 扩展性能无噪信道，C只决定于输入符号数n
> **答案：B**（一一对应C=log n，决定于输入符号数）

### 课件例题

**例4.1.1（互信息量计算）**
天气信源，收到消息"今天不是晴天"。求 b₁ 与各天气的互信息量。

> 原来：p(晴)=1/2, p(阴)=1/4, p(雨)=1/8, p(雪)=1/8
> 收到b₁后：p(晴|b₁)=0, p(阴|b₁)=1/2, p(雨|b₁)=1/4, p(雪|b₁)=1/4
>
> I(阴;b₁) = log(½ / ¼) = log₂2 = 1 bit
> I(雨;b₁) = log(¼ / ⅛) = log₂2 = 1 bit
> I(雪;b₁) = log(¼ / ⅛) = log₂2 = 1 bit

**例4.1.2（平均互信息量计算）**
信源 X={a₁(0.5), a₂(0.5)} 接入信道 p(b₁|a₁)=0.98, p(b₂|a₁)=0.02, p(b₁|a₂)=0.2, p(b₂|a₂)=0.8

> 1. p(a₁b₁)=0.49, p(a₁b₂)=0.01, p(a₂b₁)=0.1, p(a₂b₂)=0.4
> 2. p(b₁)=0.59, p(b₂)=0.41
> 3. H(X)=1, H(Y)=0.98, H(XY)=1.43
> 4. I(X;Y)=H(X)-H(X|Y)=1-0.45=0.55 bit/sign

**例4.2.2（一般信道容量计算）**
P = [[1, 0], [ε, 1-ε]]，求 C。

> β₁=0, β₂=log ε·(1-ε)^{1-ε}...（具体按4.7节步骤计算）

## 四、常见易错点

1. I(X;Y) 对 p(a_i) **上凸**，对 p(b_j|a_i) **下凸**——分别对应极大值和极小值
2. 信道容量是信道的属性，不是信源的属性
3. 互信息量可为负值，但平均互信息量 ≥ 0
4. 数据处理定理：经过处理的信息量只会减少
5. 对称信道≠强对称信道：强对称要求 n=m 且矩阵对称
