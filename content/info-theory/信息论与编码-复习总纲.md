### 真题高频必考点（连续两年均出现）
1. **熵的计算链**：从联合概率表 → H(X), H(Y), H(XY), H(X|Y), I(X;Y) → 扩展熵
2. **马尔科夫信源**：平稳分布 → 极限熵 H_∞
3. **信道容量**：对称/强对称信道 C 计算 + 有噪编码定理判断可行性
4. **率失真函数**：等概率信源汉明失真 R(D) + 试验信道矩阵
5. **扩展信源赫夫曼编码**：编码效率 η
6. **线性分组码**：从 H 求 G → n/k/d_min → 伴随式译码
7. **卷积码**：栅格图 → 编码 → 维特比译码（分支度量数）
8. **连续信道**：香农公式 C=W·log₂(1+S/N) + dB换算
9. **仿射密码加密**
10. **连续信源最大熵定理**（均匀/高斯）

## 三、7天复习计划

### Day 1：第2章 离散信源熵 + 马尔科夫信源 + 连续信源最大熵（约3h）
**【核心中的核心，一切计算的基础】**
- [ ] 自信息量 I(a_i)、联合自信息量 I(a_i b_j)、条件自信息量 I(a_i|b_j)
- [ ] 信源熵 H(X)、条件熵 H(Y|X)、联合熵 H(XY)
- [ ] 熵的8个性质（非负性、对称性、最大熵定理、扩展性、确定性、可加性、极值性、上凸性）
- [ ] 最大离散熵定理证明（必会）
- [ ] 冗余度、信息变差
- [ ] **★马尔科夫信源**：平稳分布求法 → 极限熵 H_∞ = Σ p(s_i)H(X|s_i)
- [ ] **★连续信源最大熵**：限峰值(均匀分布)→log₂(b-a)；限功率(高斯分布)→½log₂(2πeσ²)
- [ ] 习题：课件例题2.2.1/2.2.2 + 真题2023计算题2（马尔科夫） + 课后p34 2.4/2.5

### Day 2：第3章 无失真离散信源编码（约3h）
- [ ] 定长编码定理、变长编码定理（理解条件）
- [ ] 唯一可译码、即时码、克拉夫特不等式
- [ ] 香农编码：累加概率 → 二进制展开 → 码长确定
- [ ] 费诺编码：概率分组 → 递归分配
- [ ] 赫夫曼编码：概率排序 → 合并缩减 → 反向分配
- [ ] 平均码长 K̄、编码效率 η = H(X)/R
- [ ] 习题：课件例题3.3.1/3.4.1/3.5.2/3.5.3 + 课后p52 3.1/3.2/3.3

### Day 3：第4章 离散信道容量 + 连续信道香农公式（约3h）
- [ ] 互信息量 I(a_i;b_j)、平均互信息量 I(X;Y)
- [ ] 互信息性质：对称性、非负性、极值性、凸函数性、数据处理定理
- [ ] 各种熵之间的关系：H(XY) = H(X)+H(Y|X) = H(Y)+H(X|Y)
- [ ] I(X;Y) = H(X)-H(X|Y) = H(Y)-H(Y|X) = H(X)+H(Y)-H(XY)
- [ ] 四类特殊信道容量计算：
  - 一一对应无噪：C = log n
  - 扩展无噪：C = log n
  - 归并无噪：C = log m
  - 强对称：C = log n - H(p) - p*log(n-1)
  - 对称：C = log m - H(q_i)（q_i为行元素集合）
  - 准对称：C = log m - H(q_i) - Σ N_k log M_k
- [ ] **★连续信道香农公式**：C = W·log₂(1+S/N)，dB换算 S/N=10^{dB/10}
- [ ] 信道容量一般计算方法（拉格朗日乘子法）
- [ ] 有噪信道编码定理：R<C 时 L足够大可无差错传输
- [ ] 习题：课件例4.1.1/4.1.2/4.2.1/4.2.2 + 真题2023计算题3/4 + 课后p89 4.3/4.5/4.6/4.10

### Day 4：第5章 纠错编码 + 卷积码（约3h）
- [ ] 码重 w(c)、码距（汉明距离）d(c,c')、最小码距 d_min
- [ ] 检错/纠错能力：l = d_min-1 可检, t = ⌊(d_min-1)/2⌋ 可纠
- [ ] 生成矩阵 G、一致校验矩阵 H：G·H^T = 0
- [ ] 系统码：G_s = [I_k | Q], H_s = [Q^T | I_{n-k}]
- [ ] 伴随式 s = r·H^T，s ≠ 0 则出错
- [ ] 汉明码：n=2^r-1, k=2^r-r-1, d_min=3, t=1
- [ ] 循环码：生成多项式 g(x) | (x^n - 1)，码式 c(x)=m(x)g(x)
- [ ] 校验多项式 h(x) = (x^n - 1)/g(x)
- [ ] 系统循环码编码：c(x) = x^{n-k}m(x) + r(x), r(x) = x^{n-k}m(x) mod g(x)
- [ ] 伴随多项式 s(x) = r(x) mod g(x)
- [ ] **★卷积码**：栅格图绘制、消息序列→码字序列、基本生成矩阵 G_B
- [ ] 习题：课件例题 + 真题2022/2023编码题3 + 课后p126 5.10/5.11/5.14/5.15

### Day 5：第7章 信息率失真函数（约3h）
- [ ] 失真函数 d(a_i,b_j)，失真矩阵 D，汉明失真
- [ ] 平均失真度 D̄ = ΣΣ p(a_i)p(b_j|a_i)d(a_i,b_j)
- [ ] R(D) 定义：R(D) = min I(X;Y)（在 D̄ ≤ D 约束下）
- [ ] R(D) 性质：定义域 [0, D_max]、下凸性、单调递减
- [ ] 二元信源 R(D) 计算（必会公式！）
- [ ] 等概率离散信源 R(D) 计算
- [ ] 信息价值 V = D_max - D(R)，价值率 dV/dR = -1/S
- [ ] C 与 R(D) 对比表（上凸 vs 下凸，极大值 vs 极小值，信道 vs 信源）
- [ ] 习题：课件例题 + 课后p166 7.1/7.3

### Day 6：第9章 + 第8章（约2.5h）
**第9章 密码安全性：**
- [ ] 完善保密性：I(P;C) = 0，必要条件 H(K) ≥ H(P)
- [ ] 唯一解距离：V ≈ H(K) / I_0∞（密钥熵 / 明文冗余度）
- [ ] 加法密码、乘法密码、仿射密码的唯一解距离计算
- [ ] 古典密码信息论分析

**第8章 限失真信源编码：**

- [ ] 物理意义：R(D) 是限失真编码的信息率下界
- [ ] H(X)、C、R(D) 三者的关系

- [ ] 2023年春期末真题模拟（限时2h）

## 四、核心公式速记卡

### 第2章
| 公式 | 说明 |
|------|------|
| I(a_i) = -log p(a_i) | 自信息量 |
| I(a_i b_j) = -log p(a_i b_j) | 联合自信息量 |
| I(a_i\|b_j) = -log p(a_i\|b_j) | 条件自信息量 |
| H(X) = -Σ p(a_i) log p(a_i) | 信源熵 |
| H(XY) = -ΣΣ p(a_i b_j) log p(a_i b_j) | 联合熵 |
| H(Y\|X) = -ΣΣ p(a_i b_j) log p(b_j\|a_i) | 条件熵 |
| H(XY) = H(X) + H(Y\|X) | 熵的可加性 |
| H(X) ≤ log n | 最大离散熵定理 |
| ξ = 1 - H_∞/H_0 | 冗余度 |

### 第3章
| 公式 | 说明 |
|------|------|
| (K̄/L) log m ≥ H(X) | 定长编码定理条件 |
| K̄ ≥ LH(X)/log m | 变长编码平均码长下界 |
| Σ m^{-k_i} ≤ 1 | 克拉夫特不等式 |
| η = H(X)/R, R = K̄ log m | 编码效率 |

### 第4章
| 公式 | 说明 |
|------|------|
| I(a_i;b_j) = log [p(a_i b_j)/(p(a_i)p(b_j))] | 互信息量 |
| I(X;Y) = ΣΣ p(a_i b_j) log [p(a_i b_j)/(p(a_i)p(b_j))] | 平均互信息 |
| I(X;Y) = H(X) - H(X\|Y) = H(Y) - H(Y\|X) | 核心关系 |
| C = max I(X;Y) | 信道容量 |
| C_sym = log m - H(q) | 对称信道容量 |

### 第5章
| 公式 | 说明 |
|------|------|
| c = mG | 线性分组码编码 |
| s = rH^T | 伴随式 |
| l = d_min - 1, t = ⌊(d_min-1)/2⌋ | 检纠错能力 |
| c(x) = m(x)g(x) | 循环码编码 |
| s(x) = r(x) mod g(x) | 伴随多项式 |

### 第7章
| 公式 | 说明 |
|------|------|
| D̄ = ΣΣ p(a_i)p(b_j\|a_i)d(a_i,b_j) | 平均失真度 |
| R(D) = min I(X;Y), D̄ ≤ D | 率失真函数 |
| R(D) = H(p) - H(D/α) | 二元汉明失真 R(D) 公式 |
| V = D_max - D(R) | 信息价值 |

### 第9章
| 公式 | 说明 |
|------|------|
| I(P;C) = 0 | 完善保密性 |
| H(K) ≥ H(P) | 完善保密性必要条件 |
| V ≈ H(K)/I_0∞ | 唯一解距离 |
