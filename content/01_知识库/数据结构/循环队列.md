- **核心思想**：把数组视为首尾相接的圆环，使用**模运算**来实现。
- **关键公式 (背诵)**：
    - **入队**：`rear = (rear + 1) % M`。
    - **出队**：`front = (front + 1) % M`。
    - **队长**：`(rear - front + M) % M` (防止负数)。
- **判满/判空难题**：如果不处理，`front == rear` 既可能表示空也可能表示满。
    - *常用解法*：**少用一个元素空间**。
        - **队空**：`front == rear`。
        - **队满**：`(rear + 1) % M == front`。
