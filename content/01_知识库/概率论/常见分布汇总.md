## 1. 均匀分布 (Uniform)
- **记号**：$X \sim U(a, b)$
- **密度函数**：
  $$f(x) = \begin{cases} \frac{1}{b-a}, & a < x < b \\ 0, & \text{其他} \end{cases}$$
- **分布函数**：
  $$F(x) = \begin{cases} 0, & x < a \\ \frac{x-a}{b-a}, & a \le x < b \\ 1, & x \ge b \end{cases}$$
- **特点**：落在某区间的概率只与区间长度有关，与位置无关（几何概型）。

## 2. 指数分布 (Exponential)
- **记号**：$X \sim E(\lambda)$ （$\lambda > 0$, 常指失效率/到达率）
- **密度函数**：
  $$f(x) = \begin{cases} \lambda e^{-\lambda x}, & x > 0 \\ 0, & x \le 0 \end{cases}$$
- **分布函数**：
  $$F(x) = \begin{cases} 1 - e^{-\lambda x}, & x > 0 \\ 0, & x \le 0 \end{cases}$$
- **核心性质：无记忆性**
  $$P(X > s+t | X > s) = P(X > t)$$
  > 含义：已经工作了 $s$ 小时的元件，再工作 $t$ 小时的概率，等同于全新元件工作 $t$ 小时的概率。

## 3. 正态分布 (Normal / Gaussian)
- **记号**：$X \sim N(\mu, \sigma^2)$
- **密度函数**：
  $$f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$
  - $\mu$：位置参数（对称轴 $x=\mu$）。
  - $\sigma$：形状参数（$\sigma$ 越小图形越尖峭，$\sigma$ 越大越平缓）。

- **标准正态分布**：$Z \sim N(0, 1)$
  - 密度 $\varphi(x)$，分布 $\Phi(x)$。
  - 重要性质：$\Phi(-x) = 1 - \Phi(x)$。

- **标准化公式 (解题核心)**：
  若 $X \sim N(\mu, \sigma^2)$，则
  $$Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$$
  计算概率时：
  $$P(a < X < b) = \Phi\left(\frac{b-\mu}{\sigma}\right) - \Phi\left(\frac{a-\mu}{\sigma}\right)$$

- **3$\sigma$ 原则**：
  $P(|X-\mu| < 3\sigma) \approx 0.9974$
