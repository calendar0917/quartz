#### Week 2: 汇编与逆向启蒙（Assembly & Reverse）

- **目标：** 建立 C 代码与汇编指令的映射能力。这是 Pwn/Re 的基本功。
    
- **任务：**
    
    1. **阅读：** CSAPP 第 3 章（程序的机器级表示）。重点看栈帧结构、寄存器传参规则。
        
    2. **实操 Lab：** **CSAPP Bomb Lab** (二进制拆弹实验)。
        
        - 这是你成为黑客的成人礼。
            
        - 要求： 熟练使用 GDB 单步调试，查看寄存器 (i r)，查看内存 (x/10gx)。
            
    3. **Code：** 手写一段 C 代码，包含 switch-case、递归、结构体指针，然后用 gcc -S 生成汇编，逐行解释每一句汇编对应的 C 逻辑。
        

#### Week 3: 栈溢出与权限劫持（Stack & Pwn）

- **目标：** 理解缓冲区溢出原理，初步接触漏洞利用。
    
- **任务：**
    
    1. **阅读：** CSAPP 第 3 章关于“缓冲区溢出”的章节。补充阅读关于 Stack Canary, NX (No-Execute) 的概念。
        
    2. **实操 Lab：** **CSAPP Attack Lab**。
        
        - Phase 1-3: Code Injection (Shellcode)。
            
        - Phase 4-5: ROP (Return-Oriented Programming)。这是重点！现代防御下 Shellcode 很难直接跑，ROP 是必修课。
            
    3. **C++ 补强：** 开始看《Effective C++》或 C++ Primer 的“内存模型”章节。写一个简单的 C++ String 类，手动管理 new/delete。
        

#### Week 4: 内存管理与堆的奥秘（Memory & Heap）

- **目标：** 攻克你最弱的 C++ 与动态内存分配。
    
- **任务：**
    
    1. **阅读：** CSAPP 第 9 章（虚拟内存）。这是全书最硬核的部分之一。
        
    2. **实操 Lab：** **CSAPP Malloc Lab**（或者它的简化版）。
        
        - 你要亲手实现一个 malloc 和 free。
            
        - 你需要设计 explicit free list, segregated list 等数据结构。
            
        - 意义： 只有写过分配器，你才知道 Heap Overflow 为什么能改写 chunk header 从而导致任意地址写。
            
    3. **Arch 特训：** 编写一个 Systemd Service，守护你自己写的这个 Allocator 测试程序，并限制其最大内存使用量（Cgroups）。
        

#### Week 5: 链接与自动化（Linking & Automation）

- **目标：** 理解程序是如何组装的，以及简单的自动化攻击脚本。
    
- **任务：**
    
    1. **阅读：** CSAPP 第 7 章（链接）。搞懂 Static vs Dynamic Linking，PLT/GOT 表的作用（这对延迟绑定攻击至关重要）。
        
    2. **实操：** 学习 pwntools (Python 库)。复盘 Attack Lab，写 Python 脚本自动生成 Payload 进行攻击，而不是手敲。
        
    3. **复盘：** 整理寒假所有 Lab 的 Writeup（解题报告）。**如果你不能清晰地写出来，说明你没懂。**
