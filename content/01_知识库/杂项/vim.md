## I. 模式切换 (The Foundation)

| 命令                        | 切换到模式        | 描述                           |
| :------------------------ | :----------- | :--------------------------- |
| **`i`**                   | Insert       | 在**光标当前位置**进入插入模式。           |
| **`a`**                   | Insert       | 在**光标后一个位置**进入插入模式 (Append)。 |
| **`o`**                   | Insert       | 在**当前行下方**插入新行。              |
| **`O`**                   | Insert       | 在**当前行上方**插入新行。              |
| **`v`**                   | Visual       | 进入**字符**可视化模式 (选中字符)。        |
| **`V`**                   | Visual       | 进入**行**可视化模式 (选中整行)。         |
| **`<C-v>`**               | Visual Block | 进入**块**可视化模式 (选中矩形块)。        |
| **`<Esc>`** 或 **`<C-[>`** | Normal       | 退出所有模式，返回 Normal 模式。         |

## II. 移动与跳转 (Navigation)

### 1. 行内移动 (Intra-line)

| 命令            | 范围  | 描述                         |
| :------------ | :-- | :------------------------- |
| **`w`**       | 单词  | 向前跳转到下一个单词开头。              |
| **`b`**       | 单词  | 向后跳转到上一个单词开头。              |
| **`e`**       | 单词  | 向前跳转到当前单词末尾。               |
| **`f{char}`** | 字符  | 向右查找 `{char}` 字符，并跳转到该字符上。 |
| **`F{char}`** | 字符  | 向左查找 `{char}` 字符，并跳转到该字符上。 |
| **`;` / `,`** | 字符  | 重复/反向重复上一个 `f/F/t/T` 查找。   |
| **`0`**       | 行   | 移动到行首（第一个字符）。              |
| **`^`**       | 行   | 移动到第一个非空白字符。               |
| **`$`**       | 行   | 移动到行尾。                     |

### 2. 跨行与文件跳转 (Inter-line & File)

| 命令                    | 范围   | 描述                                                     |
| :-------------------- | :--- | :----------------------------------------------------- |
| **`gg`**              | 文件   | 移动到文件第一行。                                              |
| **`G`**               | 文件   | 移动到文件最后一行。                                             |
| **`{数字}G`**           | 文件   | 移动到文件的指定行号。                                            |
| **`%`**               | 括号   | 在匹配的括号 **`(), [], {}`** 之间跳转。                          |
| **`{` / `}`**         | 段落   | 向上/向下跳到下一个空行或段落开头。                                     |
| **`H` / `M` / `L`**   | 屏幕   | 移动到屏幕的 **High (顶行)** / **Middle (中行)** / **Low (底行)**。 |
| **`<C-f>` / `<C-b>`** | 屏幕   | 向前/向后滚动一整屏。                                            |
| **`<C-o>` / `<C-i>`** | 跳转列表 | 跳到上一个/下一个光标跳转位置。                                       |

## III. 操作符与文本对象 (The Core)

Vim 的操作遵循 **[操作符] + [动作/文本对象]** 的模式。

### 1. 核心操作符 (Operators)

| 操作符           | 描述           | 常用示例                         |
| :------------ | :----------- | :--------------------------- |
| **`d`**       | Delete (删除)  | `dw` (删除单词) / `dd` (删除行)     |
| **`c`**       | Change (改变)  | `ciw` (改变内部单词) / `cc` (改变一行) |
| **`y`**       | Yank (复制)    | `yy` (复制一行) / `y$` (复制到行尾)   |
| **`p`**       | Paste (粘贴)   | 在光标**后**粘贴。                  |
| **`P`**       | Paste (粘贴)   | 在光标**前**粘贴。                  |
| **`>` / `<`** | Shift (缩进)   | `>i{` (增加内部花括号内容的缩进)         |
| **`=`**       | Format (格式化) | `=a{` (自动格式化整个花括号块)          |

### 2. 文本对象 (Text Objects)

| 文本对象    | 边界        | **`ci` (Change Inner)** | **`ca` (Change A round)** | 描述                                |
| :------ | :-------- | :---------------------- | :------------------------ | :-------------------------------- |
| **单词**  | `w`       | `ciw`                   | `caw`                     | **`i`** 不含空格，**`a`** 包含单词后的一个空格。  |
| **花括号** | `{` 或 `B` | `ci{` / `ciB`           | `ca{` / `caB`             | **`i`** 仅操作内容，**`a`** 包含 `{}` 符号。 |
| **圆括号** | `(` 或 `)` | `ci(` / `ci)`           | `ca(` / `ca)`             | **`i`** 仅操作内容，**`a`** 包含 `()` 符号。 |
| **引号**  | `"` 或 `'` | `ci"` / `ci'`           | `ca"` / `ca'`             | **`i`** 仅操作引号内的内容，**`a`** 包含引号本身。 |
| **标签**  | `t`       | `cit`                   | `cat`                     | 用于 HTML/XML 标签。`cat` 替换整个标签块。     |
| **段落**  | `p`       | `cip`                   | `cap`                     | **`i`** 不含周围空行，**`a`** 包含周围空行。    |

## VI. 缓冲区、窗口与标签页
Vim 的空间管理逻辑：**Buffers** 是内存中的文件，**Windows** 是查看 Buffer 的窗口，**Tabs** 是 Window 的集合。

### 1. 缓冲区管理 (Buffers)
Vim 推荐的工作流是：同时打开多个 Buffer，在其中快速切换。

| 命令                | 描述                                      |
| :---------------- | :-------------------------------------- |
| **`:ls`**         | 列出当前所有缓冲区 (Buffer List)。                |
| **`:b {N}`**      | 跳转到编号为 N 的缓冲区。                          |
| **`:b {name}`**   | 跳转到包含特定文件名的缓冲区（支持补全）。                   |
| **`:bn` / `:bp`** | 切换到 下一个 / 上一个 缓冲区。                      |
| **`:bd`**         | 删除/关闭当前缓冲区 (Buffer Delete)。             |
| **`<C-^>`**       | **神技**：在最近使用的两个缓冲区之间快速切换。               |
| **`:set hidden`** | **核心配置**：允许在未保存当前 Buffer 时切换到其他 Buffer。 |

### 2. 窗口分割 (Windows)
用于在同一屏幕内查看多个文件或同一文件的不同部分。所有命令均以 `<C-w>` (Window) 开头。

| 命令                        | 描述                       |
| :------------------------ | :----------------------- |
| **`<C-w> s`** 或 **`:sp`** | 水平分割窗口 (Split)。          |
| **`<C-w> v`** 或 **`:vs`** | 垂直分割窗口 (Vertical Split)。 |
| **`<C-w> h/j/k/l`**       | 切换到 左/下/上/右 侧的窗口。        |
| **`<C-w> w`**             | 在窗口间循环切换。                |
| **`<C-w> c`**             | 关闭当前窗口 (Close)。          |
| **`<C-w> o`**             | **Only**：关闭除当前窗口外的所有窗口。  |
| **`<C-w> r`**             | 交换窗口位置。                  |
| **`<C-w> =`**             | 自动平分所有窗口的大小。             |

### 3. 标签页 (Tabs)
Vim 中的标签页更像是一个“工作区布局”。

| 命令                   | 描述                 |
| :------------------- | :----------------- |
| **`:tabnew {file}`** | 在新标签页中打开文件。        |
| **`:tabc`**          | 关闭当前标签页。           |
| **`:tabo`**          | 关闭其他所有标签页。         |
| **`gt`** / **`gT`**  | 切换到 下一个 / 上一个 标签页。 |
| **`{N}gt`**          | 切换到第 N 个标签页。       |

### 4. 批处理 (Argument List & Do)
| 命令                                 | 描述                  |     |
| :--------------------------------- | :------------------ | --- |
| **`:args *.md`**                   | 将所有 .md 文件加入参数列表。   |     |
| **`:argdo %s/old/new/g 或 update`** | 在所有参数列表的文件中执行替换并保存。 |     |
| **`:bufdo %s/old/new/g`**          | 在当前所有打开的缓冲区中执行替换。   |     |

## V. 搜索与路径管理 (Built-in Search)

Vim 的原生搜索依赖于 `path` 配置。

| 命令 | 描述 |
| :--- | :--- |
| **`:edit **/*.md`** | 递归搜索并打开当前目录下所有的 `.md` 文件。 |
| **`:find {file}`** | 在 `path` 路径中搜索并打开文件。 |
| **`:set path?`** | 查看当前搜索路径（默认包含当前文件目录和当前工作目录）。 |
| **`:set path+=$PWD/**` | **神技**：将当前工作目录及所有子目录加入搜索路径。 |
| **`:Explore`** | 打开内置文件浏览器 `netrw`。 |

## VI. 文本内容查找 (Grep & Quickfix)

| 命令 | 模式 | 描述 |
| :--- | :--- | :--- |
| **`:vim /pat/ {file}`** | 命令 | **vimgrep**：内置搜索，将结果存入 Quickfix。 |
| **`:grep "pat" . -R`** | 命令 | 调用系统外置 `grep` 搜索。 |
| **`:copen` / `:ccl`** | 命令 | 打开 / 关闭 Quickfix 结果列表。 |
| **`:cn` / `:cp`** | 命令 | 跳转到 Quickfix 列表的 下一个 / 上一个 匹配项。 |

## VII. LazyVim 高效搜索 (Modern Search)

由于你使用 **LazyVim**，其核心搜索逻辑由 **Telescope** 驱动，这比原生命令快得多且支持模糊匹配。

| 快捷键 | 功能 | 描述 (LazyVim 默认) |
| :--- | :--- | :--- |
| **`<leader>ff`** | Find Files | 在当前项目下模糊搜索文件名。 |
| **`<leader>sg`** | Live Grep | **最常用**：全局实时内容搜索 (基于 Ripgrep)。 |
| **`<leader>fw`** | Grep String | 搜索当前光标下的单词 (Word)。 |
| **`<leader><space>`** | Root Files | 在项目根目录下查找文件。 |
| **`<leader>fb`** | Buffers | 在已打开的缓冲区中搜索。 |
| **`<leader>fr`** | Recent | 搜索最近打开过的文件 (Recent)。 |
| **`<leader>/`** | Fuzz Search | 在当前文件内进行模糊搜索。 |
| **`<C-q>`** | Send to QF | **关键**：在搜索窗口中按此键，将所有结果发送到 Quickfix。 |

## VIII. 批量搜索与替换 (Global Replace)

这是 Vim 处理多文件重构的标准流程：

1.  **搜索目标**：使用 `<leader>sg` (LazyVim) 或 `:grep` 搜索关键词。
2.  **送入列表**：如果是 Telescope 结果，按 **`<C-q>`** 将其转入 Quickfix 列表。
3.  **执行替换**：
    * `:cdo %s/旧词/新词/g | update` 
    * *解析：`cdo` 对列表中的每一行执行替换；`update` 仅在有变动时保存文件。*
4.  **手动筛选**：
    * 使用 `:Files` 选择多个文件（`<Tab>` 选中），然后执行 `:bufdo %s/old/new/g | update`。

## IX. FZF 匹配语法 (Search Syntax)

在 Telescope 或 FZF 搜索框内使用的过滤规则：

| 符号 | 示例 | 匹配逻辑 |
| :--- | :--- | :--- |
| **`^`** | `^abc` | 以 `abc` 开头。 |
| **`$`** | `xyz$` | 以 `xyz` 结尾。 |
| **`'`** | `'word` | **精确匹配**（非模糊）。 |
| **`!`** | `!temp` | **反向匹配**（不包含 temp）。 |
| **`\|`** | `a \| b` | 匹配 a **或** b。 |
