# Monolithic Kernel

## 宏内核 (Monolithic)
xv6 采用宏内核设计。
* **特点:** 所有的 OS 服务（文件系统、网络协议栈、驱动、内存管理）都运行在**同一个内核地址空间**，拥有**最高特权级**。
* **优点:** 性能高。各模块之间可以直接函数调用，无需复杂的 IPC（进程间通信）。
* **缺点:** **牵一发而动全身。** 文件系统里的一个 Bug 可能导致整个系统 Panic（死机）。安全性相对较弱。

## 对比：微内核 (Microkernel)
* Minix / Mach / Fuchsia。
* 将文件系统等服务移到用户态运行。内核只保留最核心的 IPC 和调度。
* 安全但慢。
