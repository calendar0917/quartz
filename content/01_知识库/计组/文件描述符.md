# 文件描述符 (File Descriptors)

## 什么是 FD？
FD 是一个进程级的**整数**，代表一个被打开的 I/O 对象（文件、管道、设备）。
内核维护一个表，下标即为 FD。



## 标准 FD
| FD | 名称 | 默认对象 |
| :--- | :--- | :--- |
| 0 | stdin | 键盘/输入流 |
| 1 | stdout | 屏幕/输出流 |
| 2 | stderr | 屏幕/错误流 |

## 关键系统调用
- `open(path, flags)`：打开文件并返回最小可用 FD。
- `close(fd)`：释放 FD。
- `dup(fd)`：复制一个已存在的 FD，指向同一个底层对象，共享偏移量。
