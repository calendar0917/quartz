## 一、 核心矛盾与定位
**现状**：电子科大网络空间安全大二学生，成绩 Top 10%，Arch Linux 用户，CTF 战队运维。
**痛点**：感到意义缺失，排斥新自由主义的“原子化竞争”与“绩点游戏”，渴望主体性，渴望“介入历史”而非“被历史裹挟”。
**误区**：曾认为“分析”即介入，曾认为“运维”是打杂。
**修正**：
1.  **拒绝改良主义**：不满足于修补漏洞以维护现有秩序，也不满足于个人技术精英化。
2.  **确立阶级立场**：技术不应服务于资本增殖，而应致力于**“通用智力”（General Intellect）的公有化**。
3.  **重新定义角色**：从“工具人”转变为**“数字公地的建设者”**与**“对抗性基础设施的架构师”**。

## 二、 理论基础：为什么学技术？
> "Philosophers have only interpreted the world, in various ways; the point is to change it."

1.  **技术即政治**：在数字资本主义时代，代码是法律（Code is Law），算法是生产关系。不懂底层技术，就无法触碰权力的实质。
2.  **预演性政治 (Prefigurative Politics)**：用手中的技术，在当下构建未来社会的雏形（如开源社区、去中心化网络、加密通讯）。
3.  **双重政权 (Dual Power)**：利用现有的技术资源（Arch, PVE, K8s），在私有制的海洋中建立“数字解放区”和公共基础设施。
4.  **卧底的真实含义**：进入大厂或核心体制，不是为了个人爬升，而是为了**掌握核心生产资料**，推动技术的**开源化、透明化与公共化**。

## 三、 战略路线图：反数学、重工程

**核心竞争力公式**：
$$ \text{Power} = \text{Linux Kernel (Arch)} + \text{Infrastructure (PVE/K8s)} + \text{Binary Security (Pwn)} $$

### 1. 基础设施即代码 (Infrastructure as Code) —— 掌握算力分配权
*   **当前切入点**：CTF 战队的 PVE 服务器维护。
*   **升级方向**：拒绝手工运维（网管模式），转向**自动化/云原生架构**（架构师模式）。
*   **具体技术**：
    *   **Ansible / Terraform**：实现自动化部署，练习构建可复制的数字社会。
    *   **Docker / Kubernetes**：掌握资源调度的上帝视角（赛博计划经济的雏形）。
    *   **网络架构**：VLAN、软路由、流量控制。
*   **政治意义**：构建不依赖于巨头的、自主可控的“数字避难所”。

### 2. 系统底层与二进制安全 —— 掌握审查与反审查权
*   **规避短板**：避开高阶数学（密码学理论），发挥工程折腾能力。
*   **核心领域**：
    *   **Pwn / Reverse**：通过逆向工程揭示系统的虚伪与脆弱，打破软件黑箱（赋予公众知情权）。
    *   **OS / Kernel**：深入 Linux 内核，理解权限、调度与内存管理（掌握世界的物理法则）。
    *   **Rust**：学习未来的系统级语言，替代 C/C++。
*   **政治意义**：对抗技术黑箱，制约技术极权，维护用户的数字主权。

## 四、 战术执行清单 (Actionable Items)

### 阶段一：防御与筹码 (大二上·期末)
- [ ] **稳住绩点**：保住 Top 10%。成绩是未来的“统战价值”，是为了获得进入核心领域（华为内核组、国家研究所）的入场券。
- [ ] **死磕必修**：即便不喜欢数学，也要通过《信安数基》和《密码学》，视为一种意志训练。

### 阶段二：转型与武装 (大二寒假)
- [ ] **重构 PVE**：利用 Ansible/Docker 将战队服务器升级为自动化集群。
- [ ] **语言升级**：开始系统学习 **Rust**。
- [ ] **思想武装**：
    - 阅读《大教堂与集市》（理解开源生产关系）。
    - 阅读《黑客：计算机革命的英雄》（理解第一代黑客的公有制精神）。

### 阶段三：深潜与连接 (大二下及以后)
- [ ] **内功修炼**：阅读并啃透 **《CSAPP》（深入理解计算机系统）**。
- [ ] **技能拓展**：从运维转向 **Pwn** 或 **IoT 安全**，理解内存溢出与漏洞原理。
- [ ] **社会化实践 (Socializing the Tech)**：
    - 将战队的基建方案**开源**、**文档化**，使其成为公共知识。
    - 组织技术分享，打破知识垄断，武装身边的同学。
- [ ] **科研方向**：寻找做 **系统安全 (System Security)**、**固件分析** 或 **恶意代码对抗** 的导师（避开纯理论）。
