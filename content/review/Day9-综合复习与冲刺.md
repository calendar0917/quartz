## 二、易混淆概念辨析

### 2.1 加密相关

| 概念 | 区别 |
|------|------|
| **对称加密** | 1个密钥，速度快 |
| **非对称加密** | 2个密钥，速度慢，更安全 |
| **数字签名** | 私钥签名，公钥验证，用于认证和完整性 |
| **数字证书** | 包含公钥和身份信息，由CA签发 |

### 2.2 认证相关

| 概念 | 区别 |
|------|------|
| **认证** | 验证用户身份是否正确 |
| **授权** | 确定用户权限 |
| **访问控制** | 执行授权策略 |

### 2.3 访问控制模型

| 模型 | 核心思想 | 适用场景 |
|------|---------|---------|
| **DAC** | 所有者控制 | 个人电脑 |
| **MAC** | 系统强制 | 军事、政府 |
| **RBAC** | 角色中间层 | 企业应用 |
| **ABAC** | 属性动态决策 | 云环境 |

### 2.4 安全模型

| 模型 | 保护目标 | 核心规则 |
|------|---------|---------|
| **BLP** | 机密性 | 不能向上读，不能向下写 |
| **Biba** | 完整性 | 不能向下读，不能向上写 |

### 2.5 协议层级

| 协议 | 层级 | 主要功能 |
|------|------|---------|
| **SSL/TLS** | 传输层之上 | Web安全 |
| **IPSec** | 网络层 | VPN、站点互联 |
| **Kerberos** | 应用层 | 网络认证 |

### 2.6 防火墙类型

| 类型 | 工作层级 | 特点 |
|------|---------|------|
| **包过滤** | 网络/传输层 | 快速、简单 |
| **状态检测** | 网络-应用层 | 跟踪连接状态 |
| **应用代理** | 应用层 | 最安全、最慢 |

### 2.7 检测方法

| 方法 | 原理 | 能力 |
|------|------|------|
| **基于特征** | 特征库匹配 | 检测已知攻击 |
| **基于异常** | 基线偏差 | 检测未知攻击 |

### 2.8 恶意软件

| 类型 | 依赖性 | 传播方式 |
|------|--------|---------|
| **病毒** | 需要宿主 | 感染文件 |
| **蠕虫** | 独立 | 网络自动传播 |
| **木马** | 伪装 | 用户下载 |
| **勒索软件** | 独立 | 多种途径 |

## 三、重点难点强化 ⭐

### 3.1 SSL/TLS握手协议

**必须掌握的流程**：
```
1. ClientHello（算法列表、随机数）
2. ServerHello（选定算法、随机数）
3. Certificate（服务器证书）
4. ClientKeyExchange（预主密钥）
5. Finished（验证握手）
```

**关键点**：
- 预主密钥用服务器公钥加密
- 双方用预主密钥生成会话密钥
- 会话密钥用于对称加密

### 3.2 保护域与访问控制矩阵

**访问控制矩阵**：
```
主体\客体    文件A    文件B    打印机
用户1        rwx      r        -
用户2        r        rwx      w
```

**保护域 = 矩阵的一行**

用户的保护域就是该用户对所有客体的权限集合。

### 3.3 SQL注入防御

**核心防御**：参数化查询（Prepared Statement）

**原理**：将用户输入作为数据，而不是SQL代码的一部分。

### 3.4 栈溢出原理

**关键点**：
- 返回地址在栈上
- 缓冲区溢出覆盖返回地址
- 攻击者控制程序执行流程

## 四、答题技巧

### 4.1 填空题技巧（10%）

- 注意关键词（如：对称、非对称、私钥、公钥）
- 回忆定义和特点
- 确保拼写正确

### 4.2 判断题技巧（10%）

- 找关键词（"只能"、"必须"、"所有"等绝对词，通常错）
- 回忆原理和特点
- 注意易混淆概念

### 4.3 选择题技巧（20%）

- 排除法：先排除明显错误的选项
- 关键词法：找题目中的关键词
- 联想法：回忆相关知识点
- 注意题目要求："以下哪项是正确的"还是"以下哪项是错误的"

### 4.4 简答题技巧（30%）

- 分点回答（1、2、3...）
- 先总后分（先说结论，再详细解释）
- 结合例子
- 注意答题结构
- 控制字数（100-200字）

**简答题答题模板**：
```
1. 定义/概念：xxx是指...
2. 原理/机制：其工作原理是...
3. 特点/优缺点：
   - 优点：...
   - 缺点：...
4. 应用/实例：例如...
```

### 4.5 应用题技巧（40%）

- 审题仔细，明确要求
- 分步骤分析，画图辅助
- 结合理论知识，分析实际问题
- 检查答案完整性

**应用题常见类型**：
- 流程图设计（如SSL握手、IPSec协商）
- 拓扑图分析（如防火墙部署、DMZ结构）
- 矩阵分析（如访问控制矩阵、保护域）
- 场景分析（如SQL注入攻击、缓冲区溢出）
