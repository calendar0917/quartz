## 一、恶意软件分类

### 1.1 什么是恶意软件

**恶意软件（Malware）**：设计用来破坏、干扰或未经授权访问计算机系统的软件。

### 1.2 恶意软件分类概览

| 类型 | 英文 | 特点 | 传播方式 |
|------|------|------|---------|
| **病毒** | Virus | 寄生在宿主程序 | 依附宿主传播 |
| **蠕虫** | Worm | 独立程序 | 网络自动传播 |
| **木马** | Trojan | 伪装成合法软件 | 用户下载安装 |
| **勒索软件** | Ransomware | 加密文件勒索 | 多种途径 |

### 1.3 病毒（Virus）

**定义**：寄生在宿主程序中，依赖宿主传播的恶意代码。

**特点**：
- **寄生性**：必须依附在其他程序上
- **传染性**：能感染其他程序
- **潜伏性**：可能在特定条件下触发
- **破坏性**：执行恶意操作
- **可清除**：可以通过重装系统清除

**传播方式**：
- 感染可执行文件
- 感染文档（宏病毒）
- 感染启动区

**生命周期**：
```
1. 潜伏阶段：病毒代码未激活
2. 传染阶段：感染其他程序
3. 触发阶段：满足特定条件
4. 破坏阶段：执行恶意操作
```

**典型示例**：
- CIH病毒（破坏硬件）
- 宏病毒感染Office文档

### 1.4 蠕虫（Worm）

**定义**：独立的恶意程序，能自动扫描网络漏洞并传播，不依赖宿主。

**特点**：
- **独立性**：不需要宿主程序
- **自动传播**：自动扫描并感染其他系统
- **网络性**：通过网络漏洞传播
- **爆发性**：传播速度极快

**传播方式**：
- 利用操作系统漏洞
- 利用网络服务漏洞
- 利用电子邮件

**与病毒的区别**：
| 方面 | 病毒 | 蠕虫 |
|------|------|------|
| 依赖性 | 需要宿主 | 独立运行 |
| 传播方式 | 感染文件 | 网络自动传播 |
| 传播速度 | 慢 | 快（爆发） |
| 清除方式 | 可能需重装系统 | 需要修补漏洞 |

**典型示例**：
- **莫里斯蠕虫**：1988年，利用Unix fingerd漏洞，第一个互联网蠕虫
- **冲击波蠕虫**：利用Windows DCOM RPC漏洞
- **震荡波蠕虫**：利用Windows LSASS漏洞

**与缓冲区溢出的关系**：
许多蠕虫利用缓冲区溢出漏洞进行传播，如莫里斯蠕虫、冲击波蠕虫等。

### 1.5 木马（Trojan Horse）

**定义**：伪装成合法软件的恶意程序，通过后台窃取信息或提供后门。

**特点**：
- **伪装性**：表面看起来是正常程序
- **隐蔽性**：在后台运行，用户难以察觉
- **危害性**：窃取信息、提供后门、控制计算机

**类型**：
| 类型 | 功能 |
|------|------|
| **后门木马** | 开放后门，允许远程控制 |
| **窃密木马** | 窃取密码、银行信息 |
| **键盘记录** | 记录键盘输入 |
| **僵尸木马** | 将计算机变成僵尸网络的一部分 |

**传播方式**：
- 用户下载安装（伪装成软件）
- 捆绑在其他软件中
- 社会工程学

**典型示例**：
- 灰鸽子
- 木马下载器

### 1.6 勒索软件（Ransomware）

**定义**：加密用户文件，勒索赎金的恶意软件。

**特点**：
- **加密性**：加密文件（Office文档、图片等）
- **勒索性**：要求支付赎金（通常比特币）
- **破坏性**：可能永久删除密钥
- **针对性**：针对企业和个人

**工作流程**：
```
1. 感染系统（钓鱼邮件、漏洞利用）
2. 加密重要文件
3. 显示勒索信息
4. 要求支付赎金
5. 如果不支付，可能删除密钥
```

**典型示例**：
- WannaCry（利用永恒之蓝漏洞）
- Petya
- Locky

**近年威胁**：
勒索软件是近年企业面临的主要威胁之一，造成了巨大的经济损失。

### 1.7 恶意软件防御

| 防御措施 | 说明 |
|---------|------|
| **防病毒软件** | 检测和清除已知恶意软件 |
| **及时更新** | 修补操作系统和软件漏洞 |
| **安全意识** | 不打开不明邮件和附件 |
| **防火墙** | 阻断恶意网络流量 |
| **备份** | 定期备份重要数据 |
| **最小权限** | 限制用户和程序权限 |

## 二、拒绝服务攻击（DoS）

### 2.1 什么是DoS攻击

**DoS（Denial of Service）攻击**：使目标系统无法提供正常服务的攻击。

**DDoS（Distributed DoS）**：分布式拒绝服务攻击，从多个源发起攻击。

### 2.2 SYN Flood攻击

**攻击目标**：网络层（TCP协议）

**攻击原理**：利用TCP三次握手机制，消耗服务器资源。

**TCP三次握手回顾**：
```
1. 客户端 → 服务器：SYN（请求连接）
2. 服务器 → 客户端：SYN-ACK（确认）
3. 客户端 → 服务器：ACK（确认，建立连接）
```

**SYN Flood攻击过程**：
```
1. 攻击者 → 服务器：大量SYN包（伪造源IP）
2. 服务器 → 攻击者（伪造IP）：SYN-ACK
3. 服务器等待第三步ACK（永远不会收到）
4. 服务器为每个半连接分配资源
5. 服务器资源耗尽，无法服务正常用户
```

**攻击特点**：
- 伪造源IP地址
- 利用TCP协议的缺陷
- 攻击效果好，防御困难

**危害**：
- 服务器资源耗尽
- 网络带宽耗尽
- 正常用户无法访问

**SYN Flood的详细分析**：

**为什么攻击有效**：
- TCP协议要求服务器在收到SYN后分配资源等待ACK
- 攻击者伪造大量源IP，服务器无法验证真实性
- 服务器为每个"半连接"分配内存和端口资源
- 半连接队列（SYN Queue）被填满，无法接受新连接

**资源消耗**：
- 每个半连接占用内存（通常80-120字节）
- 服务器可能同时维持数千个半连接
- CPU和内存资源被消耗殆尽
- 网络带宽被大量SYN包占用

**攻击示例**：
```
攻击者使用工具（如hping3）：
sudo hping3 -S -p 80 --flood --rand-source 目标IP

-S：发送SYN包
-p 80：目标端口80
--flood：洪泛模式
--rand-source：随机源IP
```

### 2.3 其他DoS攻击类型

| 类型 | 原理 | 目标 |
|------|------|------|
| **UDP Flood** | 发送大量UDP包 | 消耗带宽和服务器资源 |
| **ICMP Flood** | 发送大量ICMP包（Ping） | 消耗带宽和服务器资源 |
| **HTTP Flood** | 发送大量HTTP请求 | 消耗Web服务器资源 |
| **DNS放大攻击** | 利用DNS服务器放大流量 | 攻击特定目标 |

### 2.4 DoS攻击的防御

| 防御措施 | 说明 |
|---------|------|
| **防火墙** | 过滤异常流量 |
| **入侵检测系统** | 检测DoS攻击 |
| **流量清洗** | 过滤攻击流量 |
| **CDN** | 分散流量压力 |
| **限流** | 限制连接数和请求速率 |
| **SYN Cookie** | 防御SYN Flood |
| **增加资源** | 增加带宽和服务器资源 |

**SYN Cookie防御SYN Flood**：
```
服务器不立即分配资源
而是将连接信息编码到SYN-ACK的序列号中
只有收到正确的ACK才分配资源
```

## 三、跨站脚本攻击（XSS） ★

### 3.1 什么是XSS

**XSS（Cross-Site Scripting）**：跨站脚本攻击，攻击者将恶意脚本注入到用户浏览的网页中。

### 3.2 XSS的类型

| 类型 | 特点 |
|------|------|
| **存储型XSS** | 恶意脚本存储在服务器 |
| **反射型XSS** | 恶意脚本在URL中 |
| **DOM型XSS** | 恶意脚本在客户端DOM |

### 3.3 XSS的危害

- 窃取用户Cookie
- 会话劫持
- 钓鱼攻击
- 键盘记录

### 3.4 XSS的防御

- 输入验证和输出编码
- Content Security Policy（CSP）
- HttpOnly Cookie
- 用户安全意识
