## 一、防火墙基本概念

### 1.1 什么是防火墙

**防火墙（Firewall）**：在内部网络和外部网络（如互联网）之间设置的网络安全屏障。控制进出网络的流量，根据安全策略允许或拒绝数据包。

### 1.2 防火墙的作用

| 作用 | 说明 |
|------|------|
| **访问控制** | 根据规则允许或拒绝流量 |
| **流量过滤** | 检查数据包内容和属性 |
| **日志记录** | 记录网络活动，便于审计 |
| **地址转换** | NAT，隐藏内部网络拓扑 |
| **攻击防御** | 阻断恶意流量和攻击 |

### 1.3 防火墙的局限性

- 不能防御内部攻击
- 不能防御病毒（需要反病毒软件）
- 不能防御社会工程学攻击
- 性能瓶颈（可能影响网络速度）
- 配置复杂

## 二、三种防火墙类型

### 2.1 包过滤防火墙（Packet Filtering）

**工作层级**：网络层和传输层

**检查内容**：
- 源IP地址
- 目的IP地址
- 源端口
- 目的端口
- 协议类型（TCP、UDP、ICMP）

**工作原理**：
```
数据包 → 检查包头 → 匹配规则 → 允许/拒绝
```

**优点**：
- 实现简单
- 性能高（检查开销小）
- 对应用透明
- 成本低

**缺点**：
- 不能检查数据内容
- 不能跟踪连接状态
- 不能进行用户认证
- 规则复杂时难以管理

**示例规则**：
```
允许：源IP=192.168.1.0/24, 目的端口=80
拒绝：源IP=any, 目的端口=23
```

### 2.2 状态检测防火墙（Stateful Inspection）

**工作层级**：网络层到应用层

**核心特点**：跟踪连接状态，维护连接表

**工作原理**：
```
数据包 → 检查包头 → 查询连接表 → 根据状态决定允许/拒绝
                                    ↑
                              记录连接状态
```

**连接表内容**：
| 字段 | 说明 |
|------|------|
| 源IP | 发送方地址 |
| 目的IP | 接收方地址 |
| 源端口 | 发送方端口 |
| 目的端口 | 接收方端口 |
| 协议 | TCP/UDP/ICMP |
| 状态 | 连接状态（新建、已建立等） |
| 超时 | 连接超时时间 |

**优点**：
- 比包过滤更安全
- 能跟踪连接状态
- 能检测部分应用层攻击
- 性能较好

**缺点**：
- 实现复杂
- 需要更多资源
- 不能完全防御应用层攻击

**示例**：
```
允许：HTTP连接（TCP, 端口80, 状态=已建立）
拒绝：UDP端口53（防止DNS放大攻击）
```

### 2.3 应用代理防火墙（Application Proxy）

**工作层级**：应用层

**核心特点**：充当中间人，完全代理应用层通信

**工作原理**：
```
客户端 → 代理服务器 → 服务器
         ↑
    检查、过滤、记录应用层数据
```

**代理类型**：
| 类型 | 功能 |
|------|------|
| HTTP代理 | Web浏览代理 |
| FTP代理 | 文件传输代理 |
| SMTP代理 | 邮件代理 |
| DNS代理 | 域名解析代理 |

**优点**：
- 最安全（深度检查）
- 可以进行用户认证
- 可以缓存内容
- 可以过滤应用层攻击

**缺点**：
- 性能最差（代理开销大）
- 不支持所有协议
- 配置复杂
- 成本高

### 2.4 三种防火墙对比

| 方面 | 包过滤 | 状态检测 | 应用代理 |
|------|--------|---------|---------|
| **工作层级** | 网络/传输层 | 网络-应用层 | 应用层 |
| **检查深度** | 包头 | 包头+状态 | 包头+状态+内容 |
| **安全性** | 低 | 中 | 高 |
| **性能** | 高 | 中 | 低 |
| **成本** | 低 | 中 | 高 |
| **应用** | 较少 | 主流 | 高安全环境 |

### 2.5 ⚠️ 考点重点

**填空题/判断题可能考点：**
- 包过滤检查包头
- 状态检测跟踪连接状态
- 应用代理最安全但性能最差

**简答题考点：**
- 对比三种防火墙的优缺点
- 状态检测的工作原理

## 三、DMZ（隔离区）

### 3.1 什么是DMZ

**DMZ（Demilitarized Zone，隔离区/非军事区）**：在内外部网络之间建立的独立的安全缓冲区域。将对外提供服务的服务器放置于此。

### 3.2 DMZ的作用

| 作用 | 说明 |
|------|------|
| **安全隔离** | 即使DMZ被攻破，攻击者也无法直接访问内部网络 |
| **服务发布** | 对外提供服务的服务器集中放置 |
| **降低风险** | 暴露面最小化 |
| **便于管理** | 统一的安全策略和监控 |

### 3.3 DMZ中放置的服务器

- Web服务器（HTTP/HTTPS）
- 邮件服务器（SMTP/POP3/IMAP）
- DNS服务器
- FTP服务器
- 其他对外服务

### 3.4 DMZ的安全原则

1. **最小权限原则**：DMZ中的服务器只能访问必要的资源
2. **分层防御**：多层防火墙保护
3. **监控审计**：对DMZ流量进行严格监控
4. **定期更新**：及时更新DMZ服务器的补丁

### 3.5 DMZ的实际应用案例

**案例1：企业Web服务器部署**

```
场景：某电商公司需要对外提供Web服务

部署方案：
- 在DMZ中放置Web服务器
- Web服务器可以访问内部数据库服务器
- 外部用户只能访问DMZ中的Web服务器
- 即使Web服务器被攻破，攻击者也无法直接访问数据库

优势：
- 数据库服务器在内部网络，受到内部防火墙保护
- 攻击者需要突破两层防火墙才能访问数据库
```

**案例2：邮件服务器部署**

```
场景：某企业需要对外提供邮件服务

部署方案：
- 在DMZ中放置邮件服务器
- 邮件服务器接收外部邮件
- 内部用户从DMZ获取邮件
- 邮件服务器无法直接访问内部网络资源

优势：
- 即使邮件服务器被攻破，内部网络仍然安全
- 防止恶意邮件传播到内部网络
```

## 四、防火墙部署结构 ★★★★

### 4.1 屏蔽子网结构（Screened Subnet）

**特点**：使用**两个防火墙**，在它们之间建立DMZ

**结构**：
```
互联网
    ↓
外部路由器（第一道防线）
    ↓
DMZ区（Web、邮件服务器）
    ↓
内部防火墙（第二道防线）
    ↓
内部网络（数据库、内部服务器）
```

**工作流程**：
1. 外部请求到达外部路由器
2. 外部路由器过滤大部分攻击
3. 流量进入DMZ
4. DMZ服务器处理请求
5. 如需访问内部资源，需经过内部防火墙
6. 内部防火墙严格控制DMZ到内部的访问

**优点**：
- 双重保护（两道防线）
- DMZ隔离内部网络
- 灵活的访问控制
- 安全性最高

**缺点**：
- 成本高（两个防火墙）
- 管理复杂
- 需要更多网络设备

**适用场景**：
- 大型企业
- 高安全要求环境
- 需要发布对外服务的网络

### 4.2 屏蔽主机结构（Screened Host）

**特点**：使用**单个防火墙**和**堡垒主机**

**结构**：
```
互联网
    ↓
防火墙（路由器）
    ↓
堡垒主机（对外服务器）
    ↓
内部网络
```

**堡垒主机（Bastion Host）**：
- 暴露在互联网上的服务器
- 承担对外服务
- 经过特殊加固和安全配置
- 是攻击的主要目标

**工作流程**：
1. 外部请求到达防火墙
2. 防火墙过滤后转发到堡垒主机
3. 堡垒主机处理请求
4. 内部网络通过堡垒主机访问外部

**优点**：
- 成本低（单个防火墙）
- 结构简单
- 易于管理

**缺点**：
- 堡垒主机是单点故障
- 堡垒主机被攻破则内部网络暴露
- 安全性不如屏蔽子网

**适用场景**：
- 中小型企业
- 安全要求不高
- 成本有限

### 4.3 两种结构对比

| 方面 | 屏蔽子网 | 屏蔽主机 |
|------|---------|---------|
| **防火墙数量** | 2个 | 1个 |
| **DMZ** | 有 | 无 |
| **堡垒主机** | 在DMZ中 | 独立 |
| **安全性** | 高 | 中 |
| **成本** | 高 | 低 |
| **管理复杂度** | 复杂 | 简单 |
| **适用场景** | 大型企业 | 中小型企业 |

### 4.4 ⚠️ 考点重点

**填空题/判断题可能考点：**
- 屏蔽子网使用两个防火墙
- 屏蔽主机使用单个防火墙
- 堡垒主机是攻击的主要目标

**简答题/综合题考点：**

## 五、防火墙与路由器

### 5.1 防火墙与路由器的区别

| 方面 | 防火墙 | 路由器 |
|------|--------|--------|
| **主要功能** | 安全防护 | 路由转发 |
| **检查深度** | 深度检查 | 基本检查 |
| **安全策略** | 详细的安全规则 | 基本的访问控制 |
| **性能** | 相对较低 | 高 |
| **成本** | 高 | 相对较低 |

### 5.2 协作关系

防火墙和路由器协同工作：
- **路由器**：负责路由转发和基本过滤
- **防火墙**：负责深度安全检查和策略执行
- **分层防御**：路由器和防火墙共同构建安全防线

## 六、状态检测防火墙详解

### 6.1 状态检测的工作原理

状态检测防火墙维护一个**连接表（State Table）**，记录所有活跃连接的状态信息。

**工作流程**：
```
1. 新连接到达
2. 检查是否匹配规则
3. 如果允许，添加到连接表
4. 后续数据包查询连接表
5. 连接结束或超时，删除条目
```

### 6.2 连接状态

| 状态 | 说明 |
|------|------|
| **NEW** | 新建连接 |
| **ESTABLISHED** | 已建立的连接 |
| **RELATED** | 与已建立连接相关的连接 |
| **INVALID** | 无效数据包 |

### 6.3 状态检测的优点

- 能检测TCP序列号
- 能检测SYN洪泛攻击
- 性能优于应用代理
- 安全性优于包过滤
