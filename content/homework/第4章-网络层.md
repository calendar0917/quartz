### 4-01 虚电路 vs 数据报

网络层向上提供的服务有哪两种？试比较其优缺点。

<details>
<summary>答案</summary>

**虚电路服务：**

优点：能提供可靠通信服务；分组首部只需虚电路号（开销小）；分组按序到达，无重复丢失。

缺点：每次通信需建立连接（启动慢）；同一条虚电路的分组走同一路由（单点故障整条失效）；网络节点交换机昂贵复杂。

**数据报服务：**

优点：每个分组独立转发（灵活）；路由器简单便宜；网络造价低。

缺点：不能提供可靠通信服务；分组不能有序到达（可能重复丢失）；主机负担大（负责端到端可靠性）。

</details>

### 4-07 IP 地址与 MAC 地址

试说明 IP 地址和 MAC 地址的区别。为什么要使用这两种不同的地址？

<details>
<summary>答案</summary>

**区别：**
- IP 地址：逻辑地址（软件实现），网络层及以上使用，放在 IP 数据报首部，32 位
- MAC 地址：物理地址（固化在 ROM），数据链路层使用，放在 MAC 帧首部，48 位

**为什么需要两种地址？**
- 全球存在各种异构网络，使用不同 MAC 地址
- 直接基于 MAC 地址寻址极其困难，MAC 地址转换几乎不可能
- IP 编址统一解决了异构网络互连问题
- ARP 自动完成 IP→MAC 映射，对用户透明

</details>

### 4-42 NAT

什么是 NAT？NAPT 有哪些特点？NAT 的优点和缺点有哪些？

<details>
<summary>答案</summary>

**NAT**：在内部专用网络中使用本地地址，与外部通信时在边缘路由器/防火墙处将内部地址替换成全球可路由的合法注册地址。

**NAPT 特点**：多个内网主机共用 NAT 路由器上一个全球 IP 地址，通过不同 TCP 端口号区分不同连接。

**优点**：节省全球地址；处理地址交叉；增强灵活性；安全性。

**缺点**：延迟增大；配置和维护的复杂性。

</details>

### 4-11 IP 首部检验和 ⭐

设 IP 数据报使用固定首部，其各字段的具体数值如下（除 IP 地址外，均为十进制形式表示）：

```
4500  (版本+首部长度+区分服务)
0031  (总长度)
0001  (标识)
0000  (标志+片偏移)
0411  (TTL+协议)
0000  (检验和，先置0)
0A0C  (源地址前16位)
0E05  (源地址后16位)
0C06  (目的地址前16位)
0709  (目的地址后16位)
```

> 注：此处为示意，书上原题有具体值。以下为对应书上原题的标准 IP 首部字段值（16进制/二进制表示）：

试用二进制运算方法计算应当写入到首部检验和字段中的数值（用二进制形式表示）

<details>
<summary>答案</summary>

将各字段按 16 位分组（检验和字段置 0）：

```
0100 0101 0000 0000  (4, 5, 0, 0)
0000 0000 0001 1100  (0, 0, 1, 28  ← 总长度=28?)
0000 0000 0000 0001  (标识=1)
0000 0000 0000 0000  (检验和字段先置0)
0000 0100 0001 0001  (TTL=4, 协议=17?)
0000 0000 0000 0000  (——)
0000 1010 0000 1100  (源地址 10.12)
0000 1110 0000 0101  (源地址 14.5)
0000 1100 0000 0110  (目的地址 12.6)
0000 0111 0000 1001  (目的地址 7.9)
```

所有 16 位字进行**反码求和**：
- 逢二进一，最高位有进位则在最低位加 1
- 结果 = **0111 0100 0100 1110**

取**反码**得检验和：**1000 1011 1011 0001**

</details>

### 4-20 IP 数据报分片 ⭐⭐

一个数据报长度为 **4000 字节**（固定首部长度）。现经过一个网络传送，但此网络能够传送的最大数据长度为 **1500 字节**。试问应当划分为几个短些的数据报片？各数据报片的数据字段长度、片偏移字段和 MF 标志应为何数值？

<details>
<summary>答案</summary>

固定首部 = 20 字节。

原始数据部分 = 4000 − 20 = **3980 字节**
每片最大数据部分 = 1500 − 20 = **1480 字节**（必须是 8 的倍数）
3980 = 1480 + 1480 + 1020

| 分片 | 总长度 | 数据字段长度 | 片偏移 | MF |
|:--:|:--:|:--:|:--:|:--:|
| 第 1 片 | 1500 | 1480 | 0 | 1 |
| 第 2 片 | 1500 | 1480 | 185 | 1 |
| 第 3 片 | 1040 | 1020 | 370 | 0 |

片偏移计算：
- 片 1：0 / 8 = **0**
- 片 2：1480 / 8 = **185**
- 片 3：(1480+1480) / 8 = 2960 / 8 = **370**

</details>

### 4-37 RIP 路由表更新 ⭐

假定网络中的路由器 B 的路由表有如下的项目（三列分别表示"目的网络""距离"和"下一跳路由器"）：

| 目的网络 | 距离 | 下一跳 |
|:--:|:--:|:--:|
| N1 | 7 | A |
| N2 | 2 | C |
| N6 | 8 | F |
| N8 | 4 | E |
| N9 | 4 | F |

现在 B 收到从 **C** 发来的路由信息：

| 目的网络 | 距离 |
|:--:|:--:|
| N2 | 4 |
| N3 | 8 |
| N6 | 4 |
| N8 | 3 |
| N9 | 5 |

试求出路由器 B 更新后的路由表。

<details>
<summary>答案</summary>

收到 C 的报文，将距离全 +1，下一跳改为 C：

| 目的网络 | 距离+1 | 下一跳 |
|:--:|:--:|:--:|
| N2 | **5** | C |
| N3 | **9** | C |
| N6 | **5** | C |
| N8 | **4** | C |
| N9 | **6** | C |

与 B 原路由表逐项比较：
- N2：原距离 2→C → 直接更新为 (N2, **5**, C)
- N3：原表没有 → 加入 (N3, **9**, C)
- N6：原距离 8 > 5 → 更新为 (N6, **5**, C)
- N8：原距离 4 = 4 且下一跳是 E → **不更新**
- N9：原距离 4 < 6 → **不更新**

**更新后路由表：**

| 目的网络 | 距离 | 下一跳 |
|:--:|:--:|:--:|
| N1 | 7 | A |
| N2 | 5 | C |
| N3 | 9 | C |
| N6 | 5 | C |
| N8 | 4 | E |
| N9 | 4 | F |

### 4-38 eBGP / iBGP

网络如图，假定 AS1 和 AS4 运行 RIP，AS2 和 AS3 运行 OSPF。AS 之间运行 eBGP 和 iBGP。前缀 X 在 AS4 中。

1. 路由器 **R3c** 使用哪一个协议知道前缀 X？
2. 路由器 **R3a** 使用哪一个协议知道前缀 X？
3. 路由器 **R1c** 使用哪一个协议知道前缀 X？
4. 路由器 **R1d** 使用哪一个协议知道前缀 X？

<details>
<summary>答案</summary>

1. **R3c**：在 AS3 边界，通过 AS4→AS3 的 eBGP 获得 → **eBGP**
2. **R3a**：在 AS3 内部，通过 iBGP 从 R3c 获得 → **iBGP**
3. **R1c**：在 AS1 边界，通过 AS3→AS1 的 eBGP 获得 → **eBGP**
4. **R1d**：在 AS1 内部，通过 iBGP 从 R1c 获得 → **iBGP**

**规律**：AS 之间用 **eBGP**，AS 内部用 **iBGP**。

</details>

### 4-47 地址块分配

某单位分配到一个地址块 **14.24.74.0/24**。该单位需要用到三个子网，对这三个子地址块的具体要求是：子网 N1 需要 120 个地址，子网 N2 需要 60 个地址，子网 N3 需要 10 个地址。请给出地址块的分配方案。

<details>
<summary>答案</summary>

- **N1**（120 地址 → 须 2⁷=128≥120，前缀 /25）：**14.24.74.0/25**（128个地址）
- **N2**（60 地址 → 须 2⁶=64≥60，前缀 /26）：**14.24.74.128/26**（64个地址）
- **N3**（10 地址 → 须 2⁴=16≥10，前缀 /28）：**14.24.74.192/28**（16个地址）

</details>

### 4-51 CIDR 地址块

已知一 CIDR 地址块为 **200.56.168.0/21**。

1. 试用二进制形式表示这个地址块
2. 这个 CIDR 地址块包括有多少个 C 类地址块？

<details>
<summary>答案</summary>

**(1) 二进制：**

200.56.168.0 = **1100 1000.0011 1000.1010 1**000.0000 0000

> /21 表示前 21 位是网络前缀（即前两个字节 16 位 + 第三字节前 5 位）

**(2) C 类地址块数：**
